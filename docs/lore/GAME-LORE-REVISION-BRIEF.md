AGRENOR — GAME LORE REVISION BRIEF

ข้อเสนอแก้เกมสำหรับ AI พัฒนาเกม | Proposal / Implementation Brief — ไม่ใช่คำสั่งแก้ Canon อัตโนมัติ

### 1. เป้าหมายและหลักการ

ใช้ Agrenor Current Era Canon เป็นฐานความจริงของโลก และใช้เนื้อหาเกม v98.165 (commit 47350c554d1ded5d9650bcc9d7f9a04860fd8f6c) เป็นข้อมูลเกมที่ต้องตรวจและปรับ ห้ามลบตัวละคร เควส หรือข้อมูลที่มีอยู่โดยไม่ตรวจ dependency ก่อน ให้เสนอการเปลี่ยนแปลงรายรายการ พร้อมผลกระทบต่อฉาก บทสนทนา ระบบเควส และบันทึกผู้เล่น

แยกสถานะ Canon ที่อนุมัติแล้ว / ข้อมูลเกมเดิม / Proposal ใหม่ / ปริศนาที่ยังไม่เฉลย

รักษา Fernvale เป็นหมู่บ้านบ้านเกิดที่มีชีวิต ไม่ใช่ศูนย์รวมองค์กรและผู้รู้ทุกแขนง

ไม่ตั้งชื่อเมือง องค์กร ปี พิกัด ศัพท์ Vaelari หรือเฉลยตัวตน G. ใหม่เอง

แยกความรู้ของผู้เล่นช่วงต้นออกจากความจริงของการ์ดโบราณที่เฉลยภายหลัง

### 3. ปริศนาแผ่นหินโบราณ (Retcon Candidate — รออนุมัติ)

เปลี่ยนคำเรียก “จานหินโบราณ” เป็น “แผ่นหินโบราณทรงสี่เหลี่ยมผืนผ้า” ขนาดใกล้การ์ด มีลักษณะคล้ายหิน ไม่ทำงานด้วยวิธีการ์ดมนุษย์

ความจริงที่เสนอ: เป็นการ์ดเวทโบราณในสภาพยังไม่ถูกกระตุ้น ไม่ใช่การ์ดที่ “กลายเป็นหิน” เพราะปล่อยทิ้งไว้

บทนำ: โจรทิ้งแผนที่และแผ่นหินหลังต่อสู้ โอเรนตรวจสอบครั้งแรกหลังเหตุการณ์ ไม่เคยเก็บแผ่นหินมาก่อน

ช่วงต้น: ผู้เล่นเห็นเพียงจารึกที่อ่านไม่ออกและวัตถุปริศนา; ห้าม NPC เฉลยว่าเป็นการ์ด

ช่วงกลาง: เรียนรู้ Vaelari และพบความคล้ายวงจรเวท; การอ่านภาษาได้ยังไม่เท่ากับใช้งานได้

ช่วงเฉลย: เปิดเผยว่าเป็นแผ่นผนึกเวทโบราณ อาจกระตุ้นได้ด้วยเงื่อนไขเฉพาะที่ยังไม่กำหนด

อย่าทำให้แผ่นหินเป็นอาวุธทรงพลังที่สุดหรือหลักฐานสายเลือดเทพโดยอัตโนมัติ

### 4. ระบบการ์ดและการให้รางวัล — ต้องตรง Canon

การ์ดเป็นวงจรเวท ใช้พลังผู้ถือ มีเพดานกำลัง การ์ดปกติใช้ซ้ำได้ การ์ดชั่วคราวใช้ครั้งเดียวแล้วไหม้

การจงใจอัดพลังเกินเพื่อเผาการ์ดทิ้งในหน้า Status/จัดสำรับ ไม่ใช่แอ็กชันพิเศษใน combat; การ์ดปกติไหม้โดยไม่เกิดเวท การ์ดชั่วคราวเผาทิ้งได้เช่นกัน

การ์ดข้ามธาตุใช้ได้ แต่ไม่มีความสามารถเสริมของธาตุที่ไม่ตรงแก่น

รางวัลเควส อีเวนต์ ร้านค้าและชุดสุ่ม: ต้องมีผู้ผลิต/ผู้จัดเตรียมการ์ด

มอนสเตอร์/บอสอมนุษย์: ได้ชิ้นส่วนหรือสมบัติเพื่อแลก/ผลิตการ์ด ไม่เกิดการ์ดจากการตาย; หีบหรือศัตรูมนุษย์มีการ์ดได้หากครอบครองจริง

ดันเจียนเก่ากว่าศาสตร์การ์ดมนุษย์ต้องอธิบายที่มาของการ์ดมนุษย์ที่เข้ามาภายหลัง หรือแยกเป็นแผ่นผนึกโบราณ

แบ่งบริการ: Fernvale = การ์ดพื้นฐาน; ศูนย์ภูมิภาค = ช่างและตลาด; เมืองหลวง = กำกับผลิต/ผู้เชี่ยวชาญ; ซากโบราณ = หลักฐาน Vaelari (เป็น Proposal ตำแหน่ง ไม่ใช่ยืนยันที่ตั้ง)

### 5. โครงเรื่องตามจังหวะการเปิดเผย

| ช่วง | เนื้อหา/ข้อห้าม |
| --- | --- |
| ต้นเกม Fernvale | ชีวิตหมู่บ้าน เทศกาล โจร บทเรียนการ์ด แผ่นหินปริศนาและแผนที่; ไม่เฉลยการ์ดโบราณ |
| เดินทางภายในอาณาจักร | เมืองอื่นมีบทบาทจริง: การเมือง การค้า หน่วยงานการ์ด ปัญหาท้องถิ่น ตัวละครย้ายไปตามหน้าที่ |
| กลางเกม | หลักฐานศาสตร์การ์ดก่อนมนุษย์ ภาษา Vaelari และการ์ดโบราณ; ความรู้ใหม่หักล้างประวัติศาสตร์ที่มนุษย์เชื่อ |
| ช่วงหลัง | เริ่มพบคนต่างเผ่าพันธุ์และมุมมองนอกอาณาจักรโดยไม่จำเป็นต้องเปิดทุกทวีป |
