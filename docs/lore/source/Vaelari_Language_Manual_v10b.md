# 1. สถานะของ Vaelari

Vaelari เป็นภาษาศักดิ์สิทธิ์ดั้งเดิมของโลก Agrenor ซึ่งมีแกนความคิดว่าเสียงและรากศัพท์เป็นรูปของเจตจำนง ภาษาไม่เพียงบรรยายสิ่งหนึ่ง แต่จัดความสัมพันธ์ระหว่างแนวคิดให้ปรากฏเป็นเสียง คำ และจังหวะ

# 2. สองหน้าที่ของคู่มือนี้

# 3. หลักอนุรักษ์ Canon

รากเดิมมีสิทธิ์ก่อนรากใหม่

ความหมายขยายที่สมเหตุผลควรได้รับการพิจารณาก่อนสร้างคำพ้อง

คำเฉพาะหนึ่งชิ้นไม่จำเป็นต้องได้รับรากพื้นฐานใหม่

รูปสะกดเก่าที่เป็นชื่อ Canon ให้เก็บไว้จนกว่าจะผ่าน Derivation Audit

## 10. Apostrophe (') : Relational Compounding

\[Noun A\]'\[Noun B\] = B แห่ง A / A ที่มี B เป็นแก่น

ทั้งสองรากยังคงตัวตนและน้ำหนัก

ใช้กับความเป็นเจ้าของ ความสัมพันธ์ ต้นกำเนิด หรือแก่นแท้

คำหลังในชื่อเฉพาะขึ้นต้นตัวใหญ่ ส่วน grammatical suffix ใช้ตัวเล็ก

ตัวอย่าง: Vaelthoril, Mora'Sith, Shael'Thal

## 11. การหลอมคำ: Fused Compounding

\[rootA\]\[rootB\] → แนวคิดใหม่หนึ่งหน่วย

รากเดิมลดสถานะเป็นองค์ประกอบ

อนุญาตให้ตัด เพิ่ม หรือกลืนเสียงตามกฎ

ใช้กับคำนามทั่วไป คุณสมบัติ แนวคิด หรือสสารใหม่

ตัวอย่าง: Sithael, Caelimkor, Zarnlor, Grathael

## 12. Hyphen (-) : Specific Compounding

\[Descriptor/Prefix\]-\[Head Noun\]

คำแรกขยายหรือจำแนกคำหลัก

ใช้กับยศ ประเภท ตำแหน่ง ชื่อเฉพาะ และ grammatical suffix

ต่างจาก apostrophe เพราะไม่ได้แสดงเจ้าของหรือความสัมพันธ์แบบ “แห่ง”

ตัวอย่าง: Va-Velaethor, Gaerr-Chor, Kinbae-Nee

## 33. ประเด็นที่ต้องแก้ใน Lexicon / Lore / Codex เฟสถัดไป

ตรวจ apostrophe / hyphen / fused form ให้ตรงกับ derivation ที่อธิบาย

แยก Root, Morpheme, Derived Word, Proper Name และ Encyclopedia Type

แก้ตัวอย่าง -tha ให้หมายถึง “ของเจ้า/เธอ” อย่างสม่ำเสมอ

แยกการวิเคราะห์ passive เป็น ROOT-VOICE-TAM แม้รูปเขียนจะหลอม

ตรวจ Type ของรายการที่เป็นรากแต่ถูกจัดเป็น Wonder หรือหมวดสารานุกรม

เพิ่ม pronunciation, register, semantic boundary และ status ให้แต่ละรายการ

ทำ Derivation Audit กับชื่อ Canon ทุกชื่อ โดยไม่เปลี่ยนชื่อย้อนหลังโดยอัตโนมัติ

จัดทำตารางรูป High Vaelari / Common Vaelari เฉพาะคำที่มีหลักฐานหรือได้รับอนุมัติ
