## 4. เซฟและการย้ายข้อมูล (save migration)
- เซฟเรื่องอยู่ที่ `s.village.story` (ห่วงโซ่บทนำ) และ `s.village.rep[id]` (ชื่อเสียง) · เซฟสองชั้นตาม `js/resume.js` (v98.340) · การย้ายรุ่นผ่าน `js/save-migrate.js`
- **ธงใหม่ที่เสนอ** (ทุกตัวมีค่าเริ่มต้น = ยังไม่เกิด จึงไม่ต้องย้ายข้อมูลเก่า): `story.mip = { seen, joined, fed[], dark, state:'stable'|'mad'|'purified'|'sealed' }` · `story.main = { stage, war, flags{} }` · `world.infection = { [areaId]: level }`
- ผู้เล่นที่เซฟเก่า: ธงไม่มี → ถือว่าเรื่องหลักยังไม่เริ่ม · **ห้ามแตะเซฟเดิมของบทนำ** · ต้องเขียนเทสต์ย้ายเซฟ (เซฟ v98.x เก่าโหลดแล้วไม่พัง)
- ตัวแปร "ความเข้มข้นการติดเชื้อต่อพื้นที่" เปลี่ยนตามหมุดเนื้อเรื่อง **ไม่ใช่เวลา** (Canon D)

## 6. ระบบการ์ด / loot / status (ต้องตรง Canon ส่วน A §5–6)
- **ไม่เปลี่ยนระบบการ์ด** — Canon บอกมอนสเตอร์ไม่ดรอปการ์ด; ชิ้นส่วน (มายา) เป็น **วัตถุดิบ** ไม่ใช่การ์ด
- `js/chaos.js` (แก่นโกลาหลจาก Evolved) เป็นของที่มีอยู่ — ต่อยอดเป็นแหล่ง (มายา) ได้ **ต้องไม่ทำให้เกมที่เล่นอยู่เสียสมดุล**
- สถานะใหม่ `berserk` ของ Mip: ใส่ใน `status-fx.js` (ภาพ) + `flat-battle.js` (กติกา: AI หิว คุมไม่ได้ชั่วคราว) — ต้องไม่ทับสถานะเดิม
- การแปลงร่างของ Mip ยืมค่าสถานะมอนสเตอร์ (ลดทอน) ใช้ตาราง `MON` ใน `town-battle.js` · เพดานกำลัง (Canon: การ์ดมีเพดาน) → ร่างอ่อนกว่าตัวจริง
- การแปรสภาพ/ธาตุ: Mip ใช้ธาตุตามมอนสเตอร์ที่แปลง — ตรวจตารางธาตุ ×1.3/×0.7 ใน `elements.js`
