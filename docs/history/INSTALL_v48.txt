Project A v48 — Village / Market / Shared Walk / BGM

ติดตั้งแพตช์ทั้งสอง ZIP ลงโฟลเดอร์เกมเดียวกัน
1. ปิดเกมและ Asset Studio แล้วสำรองโฟลเดอร์เกมเดิม
2. แตก Project_A_v48_Village_Market_Patch.zip ทับโฟลเดอร์เกม
3. แตก Project_A_v48_BGM_Patch.zip ทับโฟลเดอร์เดียวกัน
4. เปิด index.html และรีเฟรชหน้าเกม หากเปิด Editor ค้างอยู่ให้รีเฟรชด้วย
ทั้งสองไฟล์เป็น ZIP ปกติ ไม่ใช่ไฟล์แบ่งพาร์ต ไม่ต้องนำมาต่อกัน

ไฟล์ที่ต้องลบ: ไม่มี
ไม่ลบเซฟ localStorage, เฟรมเดิน, ภาพเก่า หรือประวัติใน Asset Studio
แพตช์นี้ไม่มี js/asset-manifest.js, asset-manifest.json หรือ js/tactics-sprites.js
จึงไม่ทับเฟรมเดินและค่าจังหวะ/กลับภาพที่คุณบันทึกจาก Editor ไว้แล้ว
รายการเดินเก่าซ่อนจาก Editor และจุดเรียกใช้งานเดิมชี้มาชุดเดินหลักแทน
ไม่ต้องลบ js/village-map.js, js/village-routes.js หรือภาพแผนที่เดิม

หาก index.html มีการแก้ไขของคุณเพิ่มจากแพตช์หมู่บ้าน v1
เก็บ index.html ของคุณ และเพิ่ม/ตรวจรายการต่อไปนี้ด้วยตนเองแทนการทับ:
- เพิ่ม <link rel="stylesheet" href="css/town-font.css"> ใน head
- หลัง <script src="js/tactics-sprites.js"></script> เพิ่มเพียงครั้งเดียว:
  <script src="js/hero-motion.js"></script>
- หลังสคริปต์เกมทั้งหมด ก่อน </body> ให้มีเพียงครั้งเดียวตามลำดับ:
  <script src="js/game-bgm.js"></script>
  <script src="js/village-town-bridge.js"></script>

การใช้งาน
- ใน Asset Studio ของตัวหลัก เหลือแถวท่า "เดิน" ชุดที่ใช้ในสนามต่อสู้
- หมู่บ้านและตลาดอ่านเฟรม จังหวะ และทิศกลับด้านจากชุดเดียวกับสนามต่อสู้
- บันทึกชุดเดินลงโฟลเดอร์เกม หรือส่งออก ZIP แล้วแตกทับตามขั้นตอน Editor เดิม
- เกมที่เปิดผ่านเว็บต้นทางเดียวกับ Editor รับการเปลี่ยนชุดเดินขณะเปิดอยู่ได้
- เมื่อเปิดแบบ file:// หรือเปิดคนละต้นทาง ให้รีเฟรชเกมหลังบันทึก/แตก ZIP
- หากใช้ ZIP ต้องแตก ZIP ลงเกมก่อน เพราะงานนำเข้าที่ยังไม่บันทึกยังเป็นงานร่าง
- ถึงบ้าน/โรงตีเหล็กแล้วเปิดหน้าเดิมอัตโนมัติ ปุ่มซ้ายบนใช้กลับแผนที่หมู่บ้าน
- ตลาดเป็นฉาก 2.5D มีร้านวัตถุดิบ ร้านรับซื้ออุปกรณ์ และกระดานออร์เดอร์
- คลิกร้านหรือเมนูร้านเพื่อเดินไปใช้บริการเดิม กดทางออกเพื่อเดินกลับหมู่บ้าน
- เงิน วัสดุ ออร์เดอร์ งานคราฟต์ และต้นทุนเดินระหว่างสถานที่ใช้ระบบเดิม
- การเดินภายในตลาดไม่หักเวลา/แรงเพิ่ม เปิดกระเป๋าที่ตลาดเพื่อขายไอเทมทั่วไปได้ตามเดิม
- สถานที่ที่เกมเดิมยังไม่มีระบบ เช่น โรงแรม วิหาร และสมาคม ยังเป็นจุดเตรียมไว้

ภาพ
- อาคาร/รั้ว/ต้นไม้/ของตกแต่งเดิมใช้ภาพ PNG ต่อ ส่วนพื้นและรายละเอียดที่เหลือใช้ภาพใหม่
- เพิ่มพื้นหญ้า หินปูถนน ดิน กอหญ้า ดอกไม้ แปลงสมุนไพร บ่อสวน และร้านตลาด
- รูปทรงพื้น/ถนนและพื้นที่เดินเป็นข้อมูลเดิม ผิวพื้นที่มองเห็นใช้ texture ภาพ
- วัตถุที่บังตัวละครโปร่งใส และกลับทึบเมื่อพ้นตัวละคร
- กล้องเริ่มต้นตลาดให้เห็นภาพรวมร้านค้า ลาก/ซูม/หาตัวละครได้

เพลง
- รายการชื่อไฟล์และฉากอยู่ใน BGM_v48.txt
- โรงตีเหล็กสลับ 01 → 02 → 01 โดยไม่ขึ้นกับการคราฟต์
- เพลงหิมะบอสใช้กับมินิบอสและบอสในแผนที่หิมะ
- เพลงชัยชนะใช้ระหว่างหน้าสรุปผลชนะ และหยุดเมื่อออกจากหน้านั้น
- เพลงเปลี่ยนฉากค่อยลด/เพิ่มเสียง ไม่เปลี่ยนเพลงเมื่อเปิดกระเป๋าหรือหน้าร้าน
- บราวเซอร์เริ่มเล่นเพลงหลังคลิกหรือกดปุ่มครั้งแรก ปรับที่ ตั้งค่า → เพลง ได้
- เพลงใหม่วัดความดังหลังแปลงประมาณ -18.4 LUFS (ต่างกันไม่ถึง 0.1 LUFS)
- ระดับเพลงเริ่มต้นใช้ค่าเดิม 30% และเก็บค่าที่คุณตั้งเองไว้
- ฉากต่อสู้อื่นที่ยังไม่มีเพลงไฟล์เฉพาะ ใช้เพลงสังเคราะห์เดิมต่อ
