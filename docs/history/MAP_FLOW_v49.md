# จังหวะการเล่นในหมู่บ้าน

ใช้ตัวละครและสถานที่เป็นจุดเริ่มกิจกรรม ผู้เล่นเดินไปทำสิ่งต่าง ๆ ในโลก แทนการเลือกหน้าจากแถบเมนูตลอดเวลา

## ขั้นตอนที่ทำใน v49

1. **มองหาจุดหมาย** — ชี้อาคาร เห็นขอบขาว ภาพสถานที่ และบริการที่มี
2. **เลือกเดิน** — คลิกอาคารหรือเลือกจากรายการสถานที่ เห็นเส้นทางและวงหมายปลายทาง
3. **เดินไปจริง** — เดินตามถนนที่มี กล้องติดตามอย่างนุ่มนวล มีฝุ่นเล็กน้อยและขอบขาวช่วยแยกตัวเอกจากฉาก
4. **หยุดที่ขอบสถานที่** — แสดงภาพและถามว่าจะใช้บริการไหม สามารถยกเลิกและยืนรอได้
5. **เข้าสถานที่** — ยืนยันแล้วภาพค่อยจาง เข้าหน้าบ้าน/โรงตีเหล็กเดิม หรือตลาด 2.5D ใช้ต้นทุนเดินทางเดิม
6. **ทำกิจกรรม** — เปิดหีบ คราฟต์ ซื้อขาย หรือรับออร์เดอร์ด้วยระบบเดิม หน้าต่างเกมหลักพักการเดินเมือง
7. **กลับออกมา** — กลับที่ทางเข้าเดิม กล้องกลับมาตามตัวเอก เลือกจุดหมายต่อไป

## แนวทางเสริมสำหรับรอบต่อไป (ยังไม่ได้เพิ่มระบบเหล่านี้)

- **กิจวัตร NPC**: ยามทักตอนผ่านประตู พ่อค้าเรียกลูกค้า ช่างตีเหล็กทำงานที่จุดของตน ช่วยให้บริการมีตัวตนในฉาก
- **ข่าวสารประจำวัน**: ป้ายคำขอหรือบทสนทนาบอกว่าวันนี้มีอะไรน่าทำ ใช้ข้อมูลเควสจริงเมื่อระบบพร้อม
- **เสียงตามตำแหน่ง**: เสียงน้ำพุเบาลงเมื่อเดินออกห่าง เสียงค้อนใกล้โรงตีเหล็ก เสียงผู้คนใกล้ตลาด
- **ป้ายชี้เส้นทาง**: บอกปลายทางนอกหมู่บ้านและระดับความเสี่ยง ก่อนเดินออกผจญภัย
- **จังหวะกลับจากการผจญภัย**: เดินกลับผ่านทางเข้าเมือง สรุปของที่ได้ แล้วชี้กิจกรรมถัดไป เช่น ขายของ ฝากของ หรือพัก
- **รองรับจอย**: ปุ่มเรียกเมนู ปุ่มเลือกสถานที่ใกล้ตัว และปุ่มยืนยันบริการ ให้โฟลว์เดียวกันบนคอมและแท็บเล็ต

แนะนำเริ่มจากเสียงตามตำแหน่งและ NPC ประจำสถานที่ เพราะช่วยให้ฉากดูมีชีวิต โดยยังไม่ต้องเพิ่มระบบเศรษฐกิจหรือเควสใหม่ทั้งหมด
