Asset Studio v46 — Unified Animation Workspace
แพตช์รวมสำหรับ Project A v38 และ Asset Studio v40–v45

ติดตั้ง
1. ปิด Asset Studio แล้วแตก ZIP ทับโฟลเดอร์เกมเดิมที่มี asset-studio.html
2. เปิดใหม่ กด Ctrl+Shift+R เพื่อโหลดสคริปต์ล่าสุด
3. ไม่มีไฟล์ที่ต้องลบ ไม่จำเป็นต้องลบภาพหรือเซฟเกม

วิธีใช้งานใหม่
หมวด → เลือกตัว/วัตถุ → ตารางท่า × ทิศ → เปิดตรวจ
เหลือหน้าตรวจและแก้เพียง modal เดียว ไม่มีหน้าต่างนำเข้าชุดเดินแยก
- หัวหน้าต่างบอกตัว / ท่า / ทิศที่กำลังแก้ และจำนวนเฟรม
- โหลดเฟรมชุดปัจจุบันให้ทันที
- พรีวิวเดียว: เล่น/หยุด ทีละเฟรม ความเร็วดู วนซ้ำ เงาเฟรมก่อนหน้า พื้นหลัง ซูม
- พรีวิวค้างให้เห็นขณะเลื่อนแก้เฟรมบนคอม/แท็บเล็ตแนวนอน
- ปรับทั้งชุดแยกหัวข้อชัดเจนจากช่อง X/Y ขนาด % และ ms ของแต่ละเฟรม
- เลือกเฟรม/ลากเรียงจากแถบเดียว ปุ่มลบเศษภาพเปิดแผงในหน้าต่างเดิม
- ยางลบมีหัวลบ ซูม ย้อนกลับ/ทำซ้ำ และคืนภาพเฟรมนั้น
- การแก้ไขยังไม่เปลี่ยนเกมจนกดบันทึกเข้าเกม

นำเข้าชีท/ภาพ
เปิดหัวข้อ “นำเข้าเฟรม / ชีท” แล้วเลือก แทนทั้งชุด / เพิ่มต่อท้าย / แทนเฟรมที่เลือก
เลือกไฟล์ ตัดคอลัมน์/แถว เลือกช่องที่ใช้ แล้วจัดลำดับในแถบเฟรมหลัก
Hero Walk รองรับจำนวนเฟรมเปลี่ยนได้เช่นเดิม
ชุดอื่นคงจำนวนเฟรมตามโครงเกมเดิม โดยแก้ภาพ ตำแหน่ง ขนาด เวลา และเรียงใหม่ได้
ระบบแจ้งข้อจำกัดในหน้าต่างและไม่บันทึกหากจำนวนไม่ตรง
การกลับด้าน Hero Walk: SE↔SW, NE↔NW, E↔W อยู่ในหัวข้อใช้ทิศคู่กลับด้าน

เซฟและส่งออก
- เซฟงานแก้ไขอัตโนมัติ แยกตามตัว/ท่า/ทิศและบริบทโฟลเดอร์
- “ไฟล์งาน / กู้เซฟ” ใช้เปิดงานของท่านั้น เซฟเอง หรือเปิดไฟล์งาน JSON
- “ส่งออก” รวม ชีท PNG / GIF / ไฟล์งาน JSON
- “บันทึกเข้าเกม” เขียนโฟลเดอร์ที่เชื่อม หรือดาวน์โหลด ZIP รวมงานที่รอส่งออก
- หากได้ ZIP ต้องแตกทับโฟลเดอร์เกมเพื่อให้ไฟล์เกมใช้ภาพใหม่จริง
- ชีท PNG/GIF ใช้เฟรมชุดที่กำลังแก้ รวมสเกล ตำแหน่ง และรอยลบล่าสุด
- งาน JSON จาก v42–v45 ยังเปิดได้ เลือกทิศให้ตรงไฟล์เดิมก่อน
- งานอัตโนมัติแบบเดิมมีหนึ่งชุดรวม ระบบให้เรียกคืนได้จากทิศที่ตรงกัน ไม่โยกไปทิศอื่นเงียบ ๆ

ตรวจผ่านและสีตาราง
1. ตรวจชุดที่เลือกให้ครบทุกเฟรม ยกเลิกเครื่องหมายต้องแก้เมื่อแก้เรียบร้อย
2. หากมีการแก้ไข ให้บันทึกก่อน แล้วกด “ยืนยันว่าชุดนี้ผ่าน”
3. ช่องท่า × ทิศที่ผ่าน เปลี่ยนพื้นหลังเป็นเขียวอ่อน
4. เมื่อท่านั้นผ่านครบทุกทิศที่กำหนด ทั้งแถวเปลี่ยนเป็นฟ้าอ่อน
5. ตัวละคร/มอนสเตอร์ใช้ 8 ทิศตามตารางโดยปริยาย Objects ใช้ทิศของชุดตามข้อมูล
6. ช่องที่ขาดภาพหรือยังไม่มีทิศจะไม่ถูกนับว่าผ่าน
7. เปลี่ยนภาพ ลำดับ เวลา สเกล ตำแหน่ง หรือยางลบ คืนสถานะของชุดที่กระทบเป็นรอตรวจ
สถานะตรวจอยู่ในเบราว์เซอร์ และเขียนลงข้อมูลเกมด้วยเมื่อเชื่อมโฟลเดอร์แล้วกดยืนยัน
ทิศกลับด้านมีสถานะตรวจแยกจากทิศต้นทาง

เปรียบเทียบ / กู้คืน / ขอ AI แก้
- เปิดหัวข้อเปรียบเทียบเมื่อต้องการดูชุดเดิมหรือเวอร์ชันก่อนหน้า
- กู้ชุดเดิมจากรายการในหัวข้อนี้ ไม่เปิดหน้าต่างจัดเฟรมอีกชุด
- ทำเครื่องหมายเฟรมที่ต้องแก้ เลือกประเภทปัญหาและหมายเหตุ แล้วกดส่งเฟรมให้ AI แก้
- ZIP คำขอมีภาพต้นฉบับของเฟรมเป้าหมาย/เพื่อนบ้าน และ request.json + prompt.txt

กรณีเปิดเกมด้วย file://
Chrome/Edge อาจแสดงภาพได้แต่ไม่ยอมให้แก้/ส่งออกพิกเซลของภาพ local
กด “เชื่อมโฟลเดอร์เกม” ใน modal แล้วเลือกโฟลเดอร์ที่มี assets และ asset-studio.html
ภาพที่เลือกนำเข้าผ่านตัวเลือกไฟล์แก้ได้โดยไม่ต้องเชื่อมโฟลเดอร์

ขอบเขตการบันทึกชุดทั่วไป
- ภาพที่มีช่องต้นฉบับร่วมกันใช้ไฟล์ร่วมกันเช่นเดิม การแก้จะกระทบทุกชุดที่ใช้ช่องนั้น และสถานะตรวจจะคำนวณใหม่
- กรณีแอนิเมชันอ้างเฟรมเดียวซ้ำหลายจังหวะ ต้องให้ภาพของช่องเดียวกันตรงกัน ระบบแจ้งหากขัดแย้ง
- Hero Walk เก็บภาพและข้อมูลจำนวน/เวลาเฟรมเป็นชุดใหม่ กู้ชุดเก่าได้

ผลทดสอบ
- modal เดียว โหลดและแก้ 6 เฟรมเดิม สลับ SE/NE และกู้เซฟถูกทิศ
- ยางลบเป็นแผงใน modal เดิม
- นำเข้า 10 เฟรม NE ปรับขนาดรายเฟรม ส่งออก PNG/GIF และ ZIP เกม
- บันทึกและกู้ Hero Walk เดิม และแก้ภาพ idle/ชีทมอนสเตอร์
- ตรวจสีเขียว รายการผ่านครบ 8 ทิศเป็นฟ้า และทิศขาดไม่ขึ้นฟ้า
- แก้ไขหลังผ่านคืนสถานะรอตรวจ
- เขียน PNG 6 ไฟล์พร้อม manifest ทั้งสองตำแหน่งลงโฟลเดอร์ที่เชื่อม
- สถานะตรวจผ่านเขียนลงข้อมูลเกม และหน้าจอแท็บเล็ตไม่ล้นแนวนอน
