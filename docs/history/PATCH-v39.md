# Patch v39 สำหรับ Project A v38

## วิธีติดตั้ง
1. ปิดหน้าเกมก่อนและสำรองโฟลเดอร์ v38 ไว้
2. แตก ZIP นี้ลงโฟลเดอร์ที่มี index.html ของ v38 แล้วเลือกแทนที่ไฟล์
3. เปิด index.html ใหม่ หากเปิดผ่านเว็บเซิร์ฟเวอร์ให้รีเฟรชแบบ Ctrl+F5

ZIP มีเฉพาะไฟล์ที่แก้หรือเพิ่ม ไม่มี assets ภาพที่เหมือนเดิม และเปิดเล่นเดี่ยว ๆ ไม่ได้

## ระบบการ์ด
- ต่อสู้: ใช้แล้วออกจากมือเข้ากองทิ้งทันที สิทธิ์ยังไม่เกิน 2 ใบต่อเทิร์น
- เดิน: การเลือกไพ่ยังเป็นการเตรียมก่อนเดิน สลับฟรีได้; เริ่มเดิน / ใช้ไพ่ต่อสู้ / จบเทิร์น จึงส่งไพ่ที่เตรียมไว้เข้ากองทิ้ง
- ถึง CT ของตัวละครนั้น เก็บใบที่ไม่ใช้แล้วจั่วเติมให้ครบมือเดิน 3 / ต่อสู้ 6 ใบ
- เปิดหน้าไพ่ที่จั่วทีละใบกลางจอ แล้วเคลื่อนเข้าสัญลักษณ์มือของสำรับนั้น โดยไม่บังคับเปิดพัดไพ่คำสั่ง
- สำรับหมดจึงสับกองทิ้งกลับเข้าไป แยกกองแต่ละตัวละคร
- ระหว่างเปิดไพ่ยังสั่งการไม่ได้ ความเร็วตาม 1×/2×/3× และรองรับ reduced motion

## พื้นสนาม
- ปุ่ม เสียง / เอฟเฟกต์ → พื้นสนาม → พื้นแบบเนิน (ใหม่) หรือ พื้นแบบบล็อก (เดิม)
- การลาดใช้พื้นธรรมชาติที่ต่างกัน 1 ระดับ เฉลี่ยมุมร่วม และตรึงกลางช่องตามกติกาเดิม
- พื้นหิน ราง น้ำ น้ำแข็ง โคลน และช่องวัตถุคงรูปแบบเดิม
- ไฮไลท์ การคลิกเลือก เงา การเดิน และลูกศรเลือกทิศอิงผิวเดียวกัน
- งานขอบเนินมนและภาพลาย AI ยังรอทำ ไม่ได้เปลี่ยนค่า Hit/Crit/ค่าเดิน/ความสูงในกติกา
