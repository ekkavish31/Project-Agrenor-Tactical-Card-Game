สิ่งที่เปลี่ยน
- ตัวเอกในแผนที่หมู่บ้านมีขนาด 93.6 จากเดิม 72 (+30%)
- ขอบขาวล้อมตัวเอก พร้อมฝุ่นเดินเล็กน้อย
- วัตถุโปร่งเฉพาะเมื่อวาดทับและบังตัวเอก หากตัวเอกอยู่ข้างหน้า วัตถุยังทึบ
- มีข้อมูลขอบโปร่งของภาพ เพื่อเช็กการบังได้แม้เปิดเกมแบบ file://
- ชี้ภาพอาคารจริงเพื่อไฮไลต์ขอบขาว พร้อมภาพและคำอธิบายบริการ
- เดินถึงขอบอาคารแล้วถามก่อนเข้าใช้บริการ กดไม่เข้าไม่หักเวลาเดินทางของสถานที่
- เวลาและแรงเดินทางจะใช้เมื่อยืนยันเข้าสถานที่ ตามระบบเดิม
- เมนูเกมรวมอยู่ในปุ่มเมนู เพื่อลดปุ่มเรียงเต็มแถว
- มีวงปลายทาง ปุ่มหยุดเดิน / Esc และเปลี่ยนฉากด้วยการค่อยจางภาพ
- กล้องตามบริเวณกลางตัวเอกอย่างนุ่มนวล มี stabilizer ลดการกระชากเวลาเลี้ยว
- หมู่บ้านและตลาดใช้กล้องตามตัวเอก แต่ปุ่มดูภาพรวมและ Editor เลื่อนกล้องอิสระได้
- เปิดกระเป๋าหรือหน้าต่างเกมหลัก จะพักการเดินในฉากเมือง/ตลาดจนปิดหน้าต่าง

Editor แผนที่หมู่บ้าน
เปิด เครื่องมือ > จัดตำแหน่ง แล้วเลือกเครื่องมือในช่องรายการ
1. ย้ายอาคารทั้งแปลง: ลากภาพอาคาร ถนนทางเข้าจะตามตำแหน่งใหม่
2. วางป้ายชื่อ: ลากป้ายชื่อแยกจากอาคาร เมื่อย้ายอาคาร ป้ายจะตามอาคารด้วย
3. วางจุดเข้าใช้บริการ: เลือกอาคารแล้วลากหมุดฟ้าไปขอบที่ต้องการ
   จุดเข้ายึดขอบพื้นที่ชนของอาคาร และเชื่อมทางภายในแปลงไปยังถนน
4. ดัด / ย้ายถนน: ลากจุดสีทอง ถนนที่วาดและพื้นที่เดินเปลี่ยนตามกัน
5. วาดถนนเพิ่ม: ลากบนแผนที่ ถนนใหม่ต้องเชื่อมกับถนนเดิมเพื่อเดินไปถึง
6. ลบถนนที่เลือก: ลบทั้งช่วงถนนที่เลือก ไม่ใช่ลบภาพแสดงเส้นอย่างเดียว
7. สร้างถนนอัตโนมัติใหม่: ทิ้งการดัดถนนปัจจุบันและเชื่อมตามอาคารอีกครั้ง

มี ย้อนกลับ / ทำซ้ำ และ Ctrl+Z / Ctrl+Shift+Z
ผังบันทึกอัตโนมัติในเบราว์เซอร์เดียวกัน เก็บแยกจากเซฟตัวละคร
ส่งออก JSON เก็บอาคาร ป้าย จุดเข้า และถนนครบ ใช้นำเข้าต่อบนเครื่องอื่นได้
ไฟล์พิกัดเก่าจาก v48 นำเข้าได้ โดยสร้างถนนอัตโนมัติให้
หลังแก้ถนน ดูข้อความการเชื่อมต่อในเครื่องมือ หากมีสถานที่ขาดให้เชื่อมถนนต่อ
ระบบจะไม่ให้ตัวเอกเดินข้ามสนามหญ้า/อาคารเพื่อชดเชยถนนที่ขาด

หมายเหตุ
พื้นที่ชน/ขอบเข้าบริการอ้างอิง footprint อาคาร ไม่ใช่ใบไม้/เงาที่วาดยื่นในภาพ
จุดบริการโรงแรม วิหาร ฯลฯ ที่เกมเดิมยังไม่มีระบบ ยังคงแสดงว่ายังไม่เปิด
บริการร้านภายในตลาดยังใช้หน้าซื้อขายเดิม กล้องและการโปร่งใสใช้การปรับใหม่
