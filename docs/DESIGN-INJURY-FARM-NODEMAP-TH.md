## ก. ระบบบาดเจ็บ (แยกจาก HP / Stamina)

### คำตอบของผู้ใช้ที่ใช้เป็นฐาน
- ทุกคนบาดเจ็บได้ (ตัวเอก เพื่อนร่วมทีม NPC ที่ออกไปทำงาน)
- สาเหตุ: การต่อสู้ + เหตุการณ์สุ่ม/เหตุการณ์เฉพาะ เท่านั้น
- ในสนาม: ถูกโจมตีจนล้ม → ไม่แน่ว่าเจ็บ (สุ่ม) · ถ้าเจ็บ → สุ่มส่วนที่เจ็บ
- "หนัก" = พักฟื้นที่โรงพยาบาลเท่านั้น · หายเป็น % ต่อวัน (เริ่ม 10% วันรุ่งขึ้น แล้วค่อยๆ สูงขึ้นถ้ายังไม่หาย)
- ไอเทม: เพิ่ม % หาย (ใช้ / ติดตัว) · ไอเทมป้องกัน ลดโอกาสบาดเจ็บ
- เมืองที่รักษามีผล: เมืองใหญ่ หมอดี หายไว แต่แพง
- ยกเลิกระบบ "ความสดชื่นสะสม" เดิม

### ข้อเสนอรูปแบบข้อมูล
- ส่วนร่างกาย 5 ส่วน: **หัว · ลำตัว · แขน · มือ · ขา** (ข้อเสนอ — ผู้ใช้ยก "ฯลฯ" ไว้ ยังไม่ได้ยืนยันซ้าย/ขวา)
- ระดับ: `ปกติ` → `เจ็บ` → `หนัก`
- เก็บต่อคน: `injuries = { head|torso|arm|hand|leg: { level, day0, bed } }`
- ผลเชิงกลไก (ข้อเสนอ ต้องปรับตัวเลขตอนทดสอบ):
  | ส่วน | เจ็บ | หนัก |
  |---|---|---|
  | หัว | ความแม่นลด | สู้/คุยไม่ได้ |
  | ลำตัว | HP สูงสุดลด | สู้/ทำงานหนักไม่ได้ |
  | แขน | โจมตีระยะประชิดลด | ใช้อาวุธ/คราฟต์ไม่ได้ |
  | มือ | คราฟต์/เก็บเกี่ยวช้า | คราฟต์/ปลูกไม่ได้ |
  | ขา | เคลื่อนที่ในสนามลด | เดินไม่ได้ (นอนพัก) |

### การเกิดบาดเจ็บ
1. สนามต่อสู้: ยูนิตที่ HP เป็น 0 (ล้ม) → ทอยลูกที่ 1 `P(เจ็บ) = base(≈35%) × ตัวคูณศัตรู × (1 − ลดจากไอเทมป้องกัน)` → ถ้าเจ็บ ทอยลูกที่ 2 เลือกส่วนตามตารางน้ำหนัก (ตามชนิดการโจมตีได้ในภายหลัง)
2. ระดับ: ลูกที่ 3 แยก เจ็บ/หนัก (แพ้ทั้งทีมหรือโดนหนักมาก → โอกาสหนักสูงขึ้น)
3. เหตุการณ์สุ่ม/เฉพาะ (กับดัก อุบัติเหตุฟาร์ม ตีเหล็ก ล่าสัตว์ ฯลฯ) ผ่านระบบเหตุการณ์เดิม (`js/town-events.js`, การ์ดเหตุการณ์ของแผนที่โลก) โดยแต่ละเหตุการณ์ระบุส่วน/ระดับเอง

### การรักษา
- `เจ็บ`: หายเองตามเวลาเมื่ออยู่ในเมือง/แคมป์ (ข้อเสนอ — ผู้ใช้ยังไม่ได้ระบุ ดูคำถามข้อ 3) หรือหายเร็วขึ้นด้วยยา
- `หนัก`: **ต้องฝากที่โรงพยาบาลเท่านั้น** ทุกเช้าทอยหาย: `p(วัน n) = min(cap, base + step × (n−1)) × ตัวคูณเมือง × ตัวคูณไอเทม`
  - ข้อเสนอเริ่มต้น: base 10% · step +8%/วัน · cap 85% · หายแน่นอนวันที่ 14 (กันติดไม่รู้จบ)
- **ตัวคูณเมือง** ผูกกับ `Settlements` (ขนาด: village / town / city): เมืองใหญ่ หมอดี หายไวกว่า ค่ารักษา/วัน แพงกว่า (ข้อเสนอ: หมู่บ้าน ×0.8 ถูก · เมือง ×1.0 · เมืองใหญ่ ×1.3 แพง)
- **ไอเทม** (3 ชนิด): ยาเร่งหาย (ใช้แล้วบวก %) · ของติดตัวเพิ่ม % หาย · ของป้องกัน ลด P(เจ็บ)
- **เยี่ยมไข้**: ไปที่โรงพยาบาลเห็นคนไข้ได้ (ผลของการเยี่ยม ดูคำถาม)

### ผู้นำ / การบังคับ manual
กฎจากคำตอบผู้ใช้ (สรุปใหม่ — **ตรงนี้ขอผู้ใช้ยืนยัน ดูคำถามข้อ 1**):
- ลำดับผู้นำ: `ตัวเอกที่ผู้เล่นเลือก → ตัวเอกอีกคน (ถ้าปลดล็อกแล้ว) → เพื่อนร่วมทีมตามลำดับ`
- ผู้นำ = คนแรกในลำดับที่ **ไม่มีส่วนใดเจ็บหนัก** คนที่เหลือเดินตาม (ใช้ระบบตัวตามเดิมของ `js/hero-follower.js` ขยายเป็นหลายคน)
- ตัวเอกเจ็บหนัก และอีกคนยังไม่ปลดล็อก: บังคับ manual ได้เฉพาะในเมือง งานที่ไม่ใช่การออกไปสู้ (ฟาร์ม คราฟต์ ฯลฯ) รอพักฟื้น
- ถ้าผู้นำเป็นเพื่อน (ไม่ใช่ตัวเอก): **คุยในจอสนทนา และทำเควสไม่ได้** ต้องรอตัวเอกหาย
- ทุกคนในลำดับเจ็บหนักหมด → ผู้เล่นเหลือแค่ รอเวลา/นอน ที่โรงพยาบาล

### ที่ต้องแก้ในโค้ดปัจจุบัน
- ลบระบบ "ความสดชื่นสะสม": มีในข้อความการ์ดพัก/กินอาหาร/ตั้งแคมป์ (`js/cards-data.js`, `js/core.js` `expected()`), `js/estates.js` ("HP and fatigue") ต้องไล่หาให้ครบก่อน (เก็บเป็นไฟล์เก่า ไม่ลบทิ้ง)
- สนามต่อสู้: จุดที่ยูนิตล้ม (`js/flat-battle.js`, `js/town-battle.js`) เพิ่มการทอยบาดเจ็บ
- โรงพยาบาล: ตัวอาคารมีแล้วในหมู่บ้าน (`healer`) เพิ่มเตียงฝากรักษา + จอรายชื่อคนไข้
- ตัวนำ/ตัวตาม: `js/hero-follower.js`, `HeroVariant` ขยายเป็นรายชื่อ
- การบันทึก: เพิ่ม `injuries` ต่อคนในไฟล์เซฟโลก (ต้องทำตามกฎ version/save ownership ใน `docs/TODO.md`)

## ข. ฟาร์ม · ปศุสัตว์ · กำลังคน (สไตล์ Harvest Moon PS1)

### คำตอบผู้ใช้ที่ใช้เป็นฐาน
- ปลูกได้สารพัด ทั้งยืนต้นและล้มลุก · ปศุสัตว์ทั่วไป
- เวลาที่ขับ progress ฟาร์มต้องคิดใหม่ · **เดินเฉพาะตอนเล่น** (ไม่มีทำงานตอนปิดเกม)
- ตัวเอกไม่อยู่ → ฝากแม่/เพื่อนในทีม · หรือจ้าง NPC ในเมือง (เสียเงิน) · ผู้ดูแลต้องเลือกอย่างใดอย่างหนึ่ง (เพื่อนที่ไปสำรวจกับตัวเอกดูฟาร์มไม่ได้)
- ค่าจ้างต่างกันตามนิสัยและอาชีพ/ฝีมือของ NPC
- ปศุสัตว์: ไก่ วัว แพะ แกะ

### ที่มีแล้ว
`js/garden.js` — แปลงผัก (ฤดูละ 28 วัน, รดน้ำ/ฝน, อีกา+หุ่นไล่กา, ปุ๋ย, ★1–3, เก็บซ้ำ, ตะกร้า, อัปเกรด: แปลงเพิ่ม/หุ่นไล่กา/กองปุ๋ย/ร่องน้ำ) ผูกกับที่ดินใน `js/estates.js` (ฟาร์มต้องอยู่ในที่ที่มี `farmland`) ปศุสัตว์ยังไม่มี (ในบทนำมีแค่ "จับแพะของปิ๊บ" เป็นภารกิจชั่วคราว S1)

### ข้อเสนอแบบจำลอง
**1) เวลา**
- ฟาร์มจำ `lastDay` (วันที่คำนวณล่าสุด) ทุกครั้งที่เกมเดินผ่านวัน (ตอนเล่น) คำนวณวันที่ผ่านไปทีเดียว ไม่มีตัวจับเวลาข้างนอกเกม

**2) ภาระงาน / กำลังคน**
- ภาระงานต่อวัน = Σ(แปลง × 1) + Σ(สัตว์ × น้ำหนักต่อชนิด) (ข้อเสนอ: ไก่ 0.25 · แพะ/แกะ 0.5 · วัว 1)
- กำลังคนต่อวัน = Σ(ผู้ดูแล × ฝีมือ × สุขภาพ) — ผู้ดูแลที่บาดเจ็บ (แขน/มือ/ลำตัว) ลดกำลังตามระดับ
- **ผลผลิตต่อวัน = ปกติ × min(1, กำลังคน ÷ ภาระงาน)** (ตามสัดส่วนที่ผู้ใช้ขอ)
- ผู้ดูแลที่ตั้งได้ (เลือกอย่างใดอย่างหนึ่งต่อคน): ตัวเอก (ตอนอยู่ที่ฟาร์ม) · แม่ · เพื่อนร่วมทีม (ถ้าไม่ได้ออกไปสู้/สำรวจ) · NPC จ้าง

**3) จ้าง NPC**
- ค่าจ้าง/วัน = `ฐานของอาชีพ × ฝีมือ × ตัวคูณนิสัย` (ใช้ข้อมูลอาชีพ/นิสัยของ NPC ที่มีใน `js/village-life.js` / `js/village-mind.js` — ต้องไล่ดูก่อนว่ามีค่านิสัยอะไร)
- จ่ายตอนวันเปลี่ยน ถ้าเงินไม่พอ → เลิกจ้างอัตโนมัติ

**4) ปศุสัตว์ (ข้อเสนอ — ผู้ใช้ให้เสนอเพิ่มได้)**
| ชนิด | ผลผลิตหลัก | หมายเหตุ |
|---|---|---|
| ไก่ | ไข่ทุกวัน | เล้า · ขนาดเล็ก ภาระต่ำ |
| วัว | นมทุกวัน · เนื้อเมื่อขาย | คอก · ภาระสูง |
| แพะ | นมแพะ → ชีส | เชื่อมบทนำ (จับแพะ) |
| แกะ | ขนแกะทุก N วัน → ส่งช่างทอผ้า (มี NPC เอลลา) | เชื่อมอาชีพ |
- ต้องมีอาหารสัตว์ (หญ้าแห้ง — มีของตกแต่ง `hay` อยู่แล้ว) · ขาดอาหาร = ผลผลิตลด
- สัตว์ไม่ตายในเฟสแรก (กันเรื่องรุนแรงเกินจำเป็น)

**5) พืชยืนต้น**
- ปลูกครั้งเดียว ให้ผลตามฤดูหลายปี · เสนอเป็นกลุ่ม "ไม้ผล/เถา" (ชนิดเฉพาะขอผู้ใช้เลือก — ใน canon มี หมู่บ้านไวน์ฮอลโลว์ เกี่ยวกับเถาองุ่นหรือไม่ ต้องตรวจก่อนใช้ชื่อ)

## ค. แผนที่โลกแบบ node

### คำตอบผู้ใช้
- เปลี่ยนจากกริดทั้งแผนที่ (ระยะเดินเร็วเกินไป) เป็นกราฟ node · เอากริดไปไว้ในแต่ละ node
- ความสูง: ยืนบนเนินมองเห็นช่องนอกเนินไกลขึ้น +1 ช่อง
- Region: Nor'Chorthal เต็ม + ภูมิภาคอื่นแค่แถบชายแดน
- หมอกดำ: พักไว้ก่อน · เริ่มออกแบบ node ด้วยสถานที่ที่มีอยู่แล้วได้

### node ชุดแรก (มาจาก `js/settlements.js` — ครบ 9 แห่ง)
| id | ชื่อ | ขนาด |
|---|---|---|
| fernvale | หมู่บ้านเฟิร์นเวล | village |
| brookmere | หมู่บ้านบรู๊คเมียร์ | village |
| willowshore | หมู่บ้านวิลโลว์ชอร์ | village |
| deepcairn | หมู่บ้านดีปแคร์น (เหมืองผลึก) | village |
| vinehollow | หมู่บ้านไวน์ฮอลโลว์ | village |
| thornwatch | ธอร์นวอตช์ | village |
| northgate | ด่านหินเหนือ | town |
| haven | ท่าเรือซอลต์เฮเวน | city |
| lakenhold | นครหลวงลาเคนฮอลด์ | city |
- จุดอื่นที่มีบนแผนที่เดิม (ถ้ำ รังโจร หอคอย จุดพักแรม ซากโบราณ ฯลฯ ใน `js/world-map.js` / `js/adventure-data.js`) เป็น **node ป่า/สนาม** — ต้องไล่รายการจริงจากโค้ดก่อนทำตาราง (ยังไม่ได้ตรวจครบ)
- ตำแหน่งจริงของ Fernvale ใน Nor'Chorthal ยังขาดตามที่ `WORLD-GEOGRAPHY.md` ระบุ → ใช้ตำแหน่งที่เกมมีอยู่ ไม่แต่งเพิ่ม

### โครงสร้าง (ข้อเสนอ)
```
nodes.json = { nodes: [{ id, kind: settlement|wild|landmark|border, name, region, pos:{x,y}(ภาพแผนที่), grid?: ref }],
               edges: [{ a, b, km|days, terrain, risk }] }
```
- การเดินทาง: เลือก node ปลายทาง → ใช้เวลา (วัน/ชั่วโมงเกม) ตามความยาว edge × พาหนะ/อัตราเดิน · ระหว่างทางทอยเหตุการณ์ตามความเสี่ยงของ edge (ต่อกับ "การ์ดเหตุการณ์" ที่มี)
- เข้า node: ถ้า settlement → หมู่บ้านเดิม (`village-town.html`) · ถ้า wild → กริดสำรวจ (ใช้ส่วนกริดของแผนที่โลกเดิมตัดมาเป็นแผนที่เล็ก) · มีความสูงช่วยมองไกล +1
- ภูมิภาคชายแดน: node ไม่กี่จุดต่อทิศ (เช่น เหนือ Nul'Duum, ใต้ Chel'Koranor, ตะวันตก Duna'Pharinor) — ต้องรอผู้ใช้อนุมัติว่า node ชายแดนคืออะไร (ไม่แต่งเอง)

### ลำดับย้ายระบบ
1. ตาราง node + edge จากข้อมูลเดิม (อ่านอย่างเดียว ยังไม่เปลี่ยนการเล่น)
2. หน้าแผนที่ node (วาด + เลือก + คำนวณการเดินทาง) แทนการเดินกริดข้ามแผนที่
3. เปิด node ป่าเป็นกริดสำรวจ (ใช้ระบบเดิมที่ตัดมา)
4. ย้าย W3/W4 (สมบัติ/หมอก) มาอยู่บน node ทีหลัง
