## เอฟเฟกต์ในคัตซีน (วาดด้วยโค้ด ไม่ต้องใช้ภาพเพิ่ม)
แถบดำแบบภาพยนตร์ · การ์ดชื่อบท · ภาพพื้นหลังซูม/แพน · โทนแสง (อรุณ กลางวัน อุ่น พลบค่ำ กลางคืน ถ้ำ) · ลำแสง · ดวงทองเรืองแสง · หมอก · อนุภาค (ฝุ่นทอง ประกายไฟ โคมไฟ หิ่งห้อย ผลึก ดาว ใบไม้) · แสงวาบ วงคลื่น จอสั่น · ปิดการเคลื่อนไหวเองเมื่อเครื่องตั้งค่าลดการเคลื่อนไหว

## แผน (แทนส่วนชั่วคราว)
- [ ] ฟาร์มจริงบนกริดหมู่บ้าน (แปลง footprint เดียวกับอาคาร) แทนปุ่มรดน้ำฟักทอง
- [ ] คอกและสัตว์จริง แทนมินิเกมจับแพะ (มินิเกมเก็บไว้เป็นอีเวนต์ได้)
- [ ] ผู้เล่นวางและซ่อมสิ่งก่อสร้างเองในเกม (ใช้ระบบวางของจาก map editor) แทนปุ่มซ่อมแผง
- [ ] สูตรคราฟต์โคม/ของตกแต่งในระบบคราฟต์จริง
- [ ] ร้านคู่แข่ง (เกรเวน) ที่ตั้งราคาแข่ง และยอดขายวันงาน
- [ ] ระบบธาตุของตัวเอก: การ์ดธาตุดินใบแรก และการแตกสายธาตุภายหลัง
- [ ] ฉากต่อสู้คืนเทศกาลบนลานหมู่บ้านจริง (ตอนนี้ใช้สนาม "ลานฝึกริมป่า")
- [ ] เชื่อม world map + หมอกดำ (`world-map.html`) กับแผนที่สมบัติ ให้เปิดหมอกรอบหมู่บ้านทีละโซน
- [ ] กระดานเควสของหมู่บ้านหลังจบบทนำ และเส้นทางไปเมืองใหญ่
- [ ] ภาพ portrait ของ NPC (แม่ ผู้ใหญ่บ้าน ปิ๊บ ลุงทอม เกรเวน ยาม) ตอนนี้เป็นวงกลมตัวอักษร
- [ ] เสียงประกอบคัตซีน (หอน ค้อน ระเบิดแก่น)
