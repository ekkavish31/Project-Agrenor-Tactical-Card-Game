# คู่มือสไตล์ภาพ — Project A (v15)

แนบไฟล์นี้ + ภาพอ้างอิงที่ระบุ ไปกับทุกชุดคำขอ (Asset Studio → 🧩 ชุดคำขอ ใส่ prompt และภาพสไตล์ให้แล้ว)

## โทนรวมของเกม
- แฟนตาซีอนิเมะ ตัวละครสัดส่วนกึ่ง SD (chibi-leaning) ลายเส้นสะอาด ลงสีแบบ cel-shaded มีแสงเงานุ่ม
- แสงอุ่นสีอำพัน สีหลักเขียวป่า/น้ำตาล ไม่ใช้สีสะท้อนแสงจัด
- ห้ามมีตัวหนังสือ กรอบ โลโก้ หรือลายน้ำในภาพ
- ภาพอ้างอิงหลัก: `assets/tactics/hero_se_idle.webp` (ตัวละครในสนาม) · `assets/adventurer-sword-idle.webp` (ตัวเอกเต็มตัว) · `assets/sword.webp` (ภาพไอเทม)

## พื้นโปร่งใส
- ภาพที่ต้องโปร่งใส (ตัวละคร มอนสเตอร์ อาวุธในมือ) ให้เจนบน **พื้นเขียวล้วน #00FF00** ไม่มีเงาบนพื้น ไม่มีไล่สี
- Asset Studio ลบพื้นเขียวและตัดขอบให้เอง

## ตามหมวด
| หมวด | ขนาด | โปร่งใส | ทิศ / การจัดวาง |
|---|---|---|---|
| ตัวละครในสนาม (ตัวเอก/เพื่อน) | 384×384 | ✓ | เท้าอยู่กลางล่าง · มือว่าง (เกมติดอาวุธให้) · ทำแค่ SE (หันขวาล่าง) และ NE (หันขวาบน เห็นหลัง) — ทิศซ้ายเกมกลับภาพให้ |
| มอนสเตอร์ ด้านหน้า | 512×768 | ✓ | หันซ้ายล่าง (3/4) · เท้ากลางล่าง · เต็มตัวไม่โดนตัด |
| มอนสเตอร์ ด้านหลัง | 512×768 | ✓ | หันซ้ายบน (หันหลังให้กล้อง) · ออกแบบเหมือนด้านหน้าทุกจุด — แนบภาพด้านหน้าเป็นอ้างอิง |
| อาวุธในมือ (สนาม) | ตามรายการ (กว้างแคบ สูง) | ✓ | วางตั้งตรงชี้ขึ้น ด้ามอยู่ล่างกลาง (จุดหมุน) อาวุธชิ้นเดียว |
| ภาพการ์ด (ของใช้ ไอเทม เหตุการณ์ แอ็กชัน เคลื่อนที่) | 1120×800 (7:5) | – | วัตถุหลักชิ้นเดียวอยู่กลาง เว้นขอบรอบ ๆ (กรอบการ์ดตัดขอบเล็กน้อย) · พื้นหลังเข้ม ไม่รก |
| ภาพอาวุธ/ไอเทมคราฟต์ | 900×900 | – | วางบนผ้าเข้มบนโต๊ะช่าง แบบเดียวกับ `assets/sword.webp` |
| พื้นหลังพื้นที่ผจญภัย | 1920×1080 | – | ภาพบรรยากาศกว้าง ไม่มีตัวละคร กลางภาพโล่ง (สนามต่อสู้และแผนที่จะวางทับ) |

## มาตรฐานภาพต่อตัวละคร (ใช้ทุกครั้งที่เพิ่มตัวละครใหม่)
| ระดับ | ใคร | ภาพ |
|---|---|---|
| 1 | ทุกตัว | ภาพการ์ด/หน้าตัวละคร 1 · ในสนาม SE + NE × (ยืน เงื้อ ฟาด ตั้งรับ โดนตี ล้ม) = 12 · (เดิน 6 เฟรม × 2 ทิศ ถ้าต้องการ) |
| 2 | ตัวที่เป็นผู้นำทีมได้ | หมู่บ้าน: ยืน · เดิน · ท่าทำงาน (ยื่นมือทำงานท่าเดียว ใช้ทุกจุด) · พัก · กิน · นอน — ชุดประจำตัวของตัวเอง |
| 3 | ไม่ผูกตัวละคร | เอฟเฟกต์ที่จุดทำงาน (ไฟเตา ประกายทั่ง ไอน้ำถังชุบ) — วาดด้วยโค้ด |
- ท่าในสนามต้องตรงกับภาพฮีโร่ท่าเดียวกัน (ขนาด ตำแหน่งตัว และตำแหน่งมือ) เพราะเกมติดอาวุธที่มือตามตำแหน่งของฮีโร่ — แนบ `tactics-hero-<ทิศ>-<ท่า>` เป็นอ้างอิงท่าทาง
- ไม่ต้องมีชุดช่างหรือชุดเปลี่ยนตามอาชีพ ทุกตัวใส่ชุดประจำตัวของตัวเอง
