## 2) วิธีเล่น — ลดการ "คลิกปุ่ม" เปลี่ยนเป็นการเล่นด้วยมือ
- **ชนแล้วโต้ตอบ (bump-to-interact):** เดินเข้าประตูค้าง ~0.4 วิ = เข้า · เดินชน NPC = ทักทาย (ใช้ได้ทั้งจอยสติ๊กและคีย์บอร์ด)
- **กดค้าง A = วงล้อตัวเลือก:** คุย / ถาม / ให้ของ / จ้างงาน (แทนกล่องปุ่มแถวยาวที่ต้องจิ้มทีละปุ่ม) เลือกด้วยจอยสติ๊ก
- **ปุ่ม A ใช้กับของทุกอย่าง:** นั่งม้านั่ง (ข้ามเวลา) · ขุด/ปลูก/เก็บในไร่ · ตกปลา · นอนเตียง (ตอนนี้เป็นปุ่มเมนู)
- **การต่อสู้แบบตาราง:** ขยับเคอร์เซอร์ช่องด้วยจอยสติ๊ก · A = ยืนยัน · B = ยกเลิก · ปัดการ์ดขึ้นเพื่อใช้ (แท็บเล็ต) · เลื่อนกล้องตามหน่วยที่เลือกเอง
- **รองรับจอยเกมแพด (Gamepad API):** ใช้ `TouchControls.vec()` / `act()` ตัวเดิม เพิ่มได้ในไม่กี่สิบบรรทัด
- **สั่นเบา ๆ (haptic)** ตอนกดปุ่มและตอนมีของให้เก็บ (ใส่แล้ว 12ms ตอนกด A)
- **คำแนะนำบนปุ่ม:** ปุ่ม A บอกกริยาเสมอ ("คุย · ฮิลดา", "เข้า · บ้านชาวนา…") — ขยายให้บอกเควสต์ ("★ ส่งแพะให้ปิ๊บ") ได้

## 3) ภาพและรายละเอียด
- **การบัง:** ใช้กล่องฐาน + วงกลม (น้ำพุ) แล้ว · ขั้นถัดไป: ให้อาคารที่ซับซ้อนมี `occluder` ของตัวเอง (หน้าจั่ว/ชายคาที่ตัวละครเดินลอดได้) แทนการลดความทึบทั้งหลัง
- **ไอโซเมตริกให้ตรงกัน:** เครื่องมือ "↔ ยืดด้านเดียว" + "📐 ปรับมุมฐาน" ใน Workshop แก้ภาพ AI ที่สร้างผิดมุมได้ · เพิ่ม: ตัวตรวจ "ฐานสมมาตร 2:1" ให้คะแนนทุกอาคารในคลัง
- **ชีทรวมแยกเป็นชิ้นเดี่ยว:** ทำแล้ว (Props 8 ชิ้น + ปุ่ม ✂ แยกชีท) · ต่อไป: ให้เกมอ่านจากไฟล์ชิ้นเดี่ยวแทน `props.webp` เพื่อแก้ทีละชิ้นได้จริง และสุ่มหมุน/พลิกได้
- **ชีวิตในฉาก:** ต้นไม้โยกตามลม (มี `tree-motion-demo.html` แล้ว) · ผิวน้ำพุกระเพื่อม · นกบินผ่านตอนเช้า · แสงหน้าต่างเรืองตอนค่ำที่ตรงกับ `TownMood`
- **UI ชุดเดียว:** ไอคอนเมนูทั้งเกม + HUD + ปุ่มจอยสติ๊กใช้ชุด `assets/icons/menu` เดียวกันแล้ว · ต่อไป: กรอบการ์ด/กล่องคุยใช้ชุด `ui-packs` และกำหนดสเกลตัวอักษร 3 ระดับ
- **ความคมภาพ:** เลือกระดับรายภาพได้ใน Workshop แล้ว (ความคม/ขอบนุ่ม) · เพิ่มค่าเริ่มต้นตามหมวด (อาคารคม ต้นไม้นุ่ม)
