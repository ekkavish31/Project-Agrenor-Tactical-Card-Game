## 1. สิ่งที่ตัดสินแล้ว

1. **[ตัดสินแล้ว] บทพูดของ NPC แต่ละตัวคำนวณจาก 5 ชั้น**
   | ชั้น | เนื้อหา | ใครเป็นผู้สร้างข้อมูล |
   |---|---|---|
   | L0 ตัวตน | นิสัย บุคลิก น้ำเสียง ประวัติเบื้องหลัง สิ่งที่ชอบ/ไม่ชอบ | เขียนมือ อิงแคนอน |
   | L1 เส้นเรื่อง | เส้นเรื่องหลัก/รองที่ดำเนินไปและเกี่ยวข้องกับ NPC คนนี้ | เขียนมือ อิงแคนอน |
   | L2 เมือง | Background ของเมืองที่ NPC สังกัด ที่เปลี่ยนตามเส้นเรื่อง | สถานะเกม + เขียนมือ |
   | L3 log กิจกรรม | สิ่งที่ NPC คนนี้เคยทำ (เก็บเป็น log ต่อคน) | ระบบบันทึกเอง |
   | L4 log ความสัมพันธ์ | NPC อื่น ตัวเอก เพื่อนร่วมทาง ที่เคยปฏิสัมพันธ์ด้วย (log ต่อคน) | ระบบบันทึกเอง |
2. **[ตัดสินแล้ว] ไม่เขียนบทให้ครบทุกความเป็นไปได้** ใช้ 3 ระดับ
   - **ระดับ A · บทเขียนมือ** จำนวนน้อย คุณภาพสูง เฉพาะจังหวะสำคัญของ NPC ที่มีเส้นเรื่อง
   - **ระดับ B · ประกอบจากแม่แบบ** แม่แบบต่อบุคลิก (voice) เติมช่องจากข้อมูลจริงของ L0–L4
   - **ระดับ C · fallback** ถอยทีละชั้นจนถึงคุยเล่นตามบุคลิก (ระบบเดิม) ไม่มีวันเงียบหรือพูดผิดบริบท
3. **[ตัดสินแล้ว] ไม่ใช้ AI เขียนบทสดในตัวเกม** ใช้ AI ช่วยร่างตอนพัฒนาได้ แต่ผู้สร้างตรวจก่อนเข้าเกม
4. **[ตัดสินแล้ว] ต่อยอดจาก Village Mind เดิม** (`js/village-mind.js`) ไม่สร้างระบบความจำที่สอง
5. **[ตัดสินแล้ว 24 พ.ย. — ผู้สร้างให้ทำตามข้อเสนอ]**
   - รายชื่อระดับ A1 ใน §3 ใช้ได้
   - นาเดีย: แหวนเจ้าเมืองคงเป็นข่าวลือ → แก้ `nadia.about` แล้ว (v98.1032) ไม่ยืนยัน/ไม่ปฏิเสธ
   - โอเรน: ระดับ A ทำเฉพาะเส้นผู้นำหมู่บ้าน ไม่แตะจานหินจนกว่า Retcon (Revision Brief §3) จะตัดสิน
   - ที่เก็บ log L3/L4: อยู่ใน `agrenor-mind-v1` เดิม (อยู่ในชุดคีย์ของ slot แล้ว: `js/run-slots.js` AUTO_KEYS, `js/console-ui.js` SLOT_KEYS) พร้อมย่อ log ไม่ย้ายเข้าเซฟหลัก

## 2. กฎที่ใช้กับทุกชั้น [ข้อเสนอ — ผู้สร้างเห็นด้วยในหลักการ 24 พ.ย.]

- **ตัวกรองความรู้ (knowledge gate)** ข้อเท็จจริงทุกข้อที่บทพูดอ้างถึงต้องมีป้าย `loreStatus` (confirmed / proposal / awaiting-lore) และ `minStage` (MainStory stage ที่เริ่มพูดได้) NPC พูดได้เฉพาะเรื่องที่ (ก) ยืนยันแล้ว (ข) ถึง stage แล้ว (ค) อยู่ในขอบเขตที่คนคนนั้นควรรู้ (Canon ส่วน A §8: คนทั่วไปไม่รู้ประวัติศาสตร์โบราณครบ)
  - ต่อยอดจากเทสต์ที่มีแล้ว `tools/test-early-dialogue-scope.cjs` (v98.1030) ซึ่งตรวจชื่อโบราณและจานหินก่อนคืนเทศกาล
- **ลำดับเมื่อหลายชั้นมีเรื่องจะพูด** เส้นเรื่องที่ต้องบอก (L1) → เรื่องระหว่าง NPC กับผู้ฟังคนนี้ (L4) → ข่าวเมือง (L2) → ความหลังของตัวเอง (L3) → คุยเล่นตามบุคลิก (L0)
- **งบต่อการคุยหนึ่งครั้ง** ไม่เกิน 1–2 เรื่อง ไม่ให้บทกลายเป็นรายงาน
- **ย่อ log** เก็บรายการละเอียดล่าสุดต่อคน (เสนอ 30–50) ส่วนที่เก่ากว่ารวบเป็น "ข้อเท็จจริงถาวร" สั้น ๆ ที่บทพูดยังอ้างถึงได้

## 4. แหล่งข้อมูลที่มีอยู่แล้วต่อชั้น (ข้อ 3 ที่ผู้สร้างมอบให้จัดการ)

### 4.2 L1 เส้นเรื่อง
- **[มีในโค้ด]** สถานะรวม: `MainStory.stage` (intro → free → signs → wake → release → chase → mine → climax → end), `war` 0–4, `infection(town)`, flags, `afterWorld` (`js/main-story.js`)
- **[มีในโค้ด]** ผูกรายคนแล้ว: เฉพาะ 7 ตัวใน `story-cast.js` (`from` + `lines: g => ...`)
- **[มีในเอกสาร]** เส้นรองที่อนุมัติ: MAIN-STORY-CANON §E · ข้อเสนอเส้นรอง `docs/PROPOSAL-SIDE-LINES-TH.md` · เรื่องย่อย `docs/PROPOSAL-SUBPLOTS-TH.md` · crossroads `js/crossroads.js`
- **ขาด:** สถานะเส้นเรื่องรายคน (NPC คนนี้อยู่ตอนไหนของเรื่องตัวเอง) · ชาวเฟิร์นเวลไม่อ่าน MainStory เลย (`village-mind.js` `village-lines.js` `town-npcs.js` `place-people.js` = 0 การอ้างอิง)

### 4.3 L2 เมือง
- **[มีในโค้ด]** `Settlements.SETTLEMENTS` + `policy()` (`js/settlements.js`) · ระดับติดเชื้อตามระยะ `DIST` (`main-story.js` บรรทัด 29: deepcairn 0 … vinehollow 3) · ราคา/ข่าวตามสงคราม `js/story-world.js` · เหตุการณ์รายวัน `js/town-events.js` · โปรเจกต์พัฒนาเฟิร์นเวล `js/village-projects.js` · ชื่อเสียงกลุ่ม `js/factions.js`
- **ขาด:** ที่เดียวที่บอกว่า "ตอนนี้เมืองนี้เป็นอย่างไร" สำหรับบทพูด · คำบรรยาย background ของเมืองที่เปลี่ยนตาม stage (มีแต่ตัวเลข) · เมืองใน `DIST` บางเมือง (northgate brookmere haven) ไม่มี LOCALS
- **[ยังไม่ได้ตรวจ]** ข้อมูลเมืองใน `docs/PROPOSAL-SETTLEMENTS.md`, `docs/lore/WORLD-GEOGRAPHY.md` ว่ามีคำบรรยายที่ใช้ได้มากแค่ไหน

### 4.4 L3 log กิจกรรม
- **[มีในโค้ด]** เฉพาะร่องรอย: `Mind.npc(id)` = `aff`, `talks`, `lastTalk`, `met`, `said`, `flags.hurtUntil` · `jobs` (งานที่ส่งไปทำ + เรื่องเล่า) · `wants` (ขอร้อง/สำเร็จ) · `counts` รวมทั้งเกม
- **ขาด:** log ถาวรต่อคน (เหตุการณ์ใน Mind หมดอายุ 2–30 วัน สูงสุด 120 รายการ แล้ว `said` ถูกลบตาม)

### 4.5 L4 log ความสัมพันธ์
