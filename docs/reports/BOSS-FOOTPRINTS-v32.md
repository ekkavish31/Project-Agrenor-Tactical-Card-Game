# ขนาดบอสและมินิบอส v32

ทุกตัวขั้นต่ำ2×2 รวมร่างคน ขนาดเป็นพื้นที่จริงในแกนโลก ไม่สลับกว้าง/ยาวเมื่อหันทิศ แต่หมุนภาพสนามตามกล้องได้

| ชนิด | พื้นที่ครอง |
|---|---|
| หัวหน้าหุ่นฟาง | 2×2 |
| จ่าฝูงหมาป่า | 2×3 |
| พฤกษาเฒ่าคลั่ง | 3×3 |
| โกเล็มหิน | 2×3 |
| ราชาโกเล็มผลึก | 3×3 |
| โทรลล์โคลน | 2×3 |
| ไฮดราบึงพิษ | 3×2 |
| กัปตันตะขอ | 2×2 |
| โกเล็มปะการัง | 3×3 |
| เยติ | 2×2 |
| ราชินีผลึกน้ำแข็ง | 2×2 |
| การ์กอยล์ | 2×2 |
| ราชาแห่งความว่างเปล่า | 2×2 |

กดเป้าหมายได้จากทุกช่อง ระยะประชิด/ยิงวัดจากขอบพื้นที่ที่ใกล้ที่สุด ตรวจแนวสายตาตามจุดบนร่างที่อยู่ในระยะ และAOEไม่ตีซ้ำเพียงเพราะทับหลายช่อง การโจมตีซ้ำที่ตั้งใจ เช่นสองคม ยังออกตามกติกาเดิม

พื้นที่ตัวใหญ่ต้านผลัก/ดึงและไม่ไถลบนพื้นน้ำแข็ง เส้นทางต้องรองรับทั้งร่างและความสูงพื้น ไม่มีการเดินผ่านวัตถุหรือยูนิตอื่น

ตอนสร้างฉากจะสงวนทางหลักหลายแนวตามขนาดที่ใหญ่ที่สุดในฉาก ปฏิเสธการวางวัตถุที่เกิดช่องแคบในแนวเดียวกัน ขยาย/ปรับระดับเส้นทางหลักถึงฝั่งผู้เล่น และลบวัตถุขนาดใหญ่ทั้งชิ้นเมื่อขวางเส้นนั้น ไม่ตัดภาพวัตถุเหลือบางช่อง ทางแคบเล็กน้อยยังมีได้ตามคำขอ

ตรวจอัตโนมัติ104สนามจาก13ชนิด ×8seed ผ่านตำแหน่งไม่ทับกัน พื้นที่ยืนได้ และมีเส้นทางกว้างพอถึงขอบฝั่งผู้เล่น
