# ตรวจงานภาพ v32 — สถานะที่นำไปเล่นจริง

## สิ่งที่ติดตั้ง
- เปลี่ยนต้นฉบับภาพของ 23 คลิปที่เคยระบุ needs-fix และเพิ่ม 240 รายการคลิปสำหรับมอนสเตอร์ 15 ชนิดที่ขาด รวม 263 รายการคลิปปรับปรุง
- 240 รายการเป็นลำดับเล่นจาก key pose ที่วาดใหม่และใช้เฟรมซ้ำตามจังหวะ ไม่ใช่ภาพแอนิเมชันเต็มที่วาดแยก 240 ชุด
- ต้นฉบับ atlas ที่ใช้จริง 28 PNG อยู่ใน assets/enemies/animations/v32/ เก็บพิกเซลต้นฉบับที่เลือกไว้ ใช้ crop/pivot/scale/flip รายเฟรมใน metadata โดยไม่ตัดทับไฟล์ภาพ
- มีภาพถุงของและผลึกสำหรับของตกบนสนามใน assets/battle-loot-v32.png
- เปิด animation-gallery-v32.html เพื่อเล่นภาพจริง 40 ชนิด และ animation-audit-v26.html เพื่อตรวจต้นฉบับ/ทิศ/เฟรม
- Asset Studio และ runtime ใช้ข้อมูล region/pivot ชุดเดียวกัน ไม่สับสนลำดับต้นฉบับกับเฟรมซ้ำในคลิป

## ผลตรวจและขอบเขต
ตรวจภาพนิ่ง/ทิศของต้นฉบับที่เลือก ตรวจ alpha/crop/pivot และทดสอบเล่น 64 กรณีในเบราว์เซอร์ ไม่มีคลิป runtime ที่ถูกบล็อก needs-fix หลังเลือกภาพสำรองที่ปลอดภัย แต่ไม่ถือเป็นการรับรองคุณภาพทุกท่าแบบ final

7 ช่องยังใช้ fallback-keypose ที่ถืออุปกรณ์ถูกมือร่วมกับ VFX/recoil:
- Frost Queen SE: strike, guard, cast
- Cultist SE: strike, guard, hit, cast

ยังต้องวาดท่าเฉพาะเหล่านี้ใหม่ ตรวจอุปกรณ์/ทิศ Skeleton ทุกมุม และเก็บ A12–A15/A18 เดิม การหัน SW/NW ของมอนสเตอร์ยังใช้การกลับภาพตามระบบเดิม ท่าดีใจแต่ละตัวเป็น pose+การเคลื่อนไหว และพิธีการบอสเป็น VFX ยังไม่มีคลิปวาดเฉพาะครบทุกตัว

## ฮีโร่ SW/NW ที่ยังไม่ผ่าน
ลองสร้างแถบเดินและเฟรมแก้ซ้ำแล้ว แต่ขาก้าวยังซ้ำข้างเดิม จึงไม่แทน runtime เดิม ไฟล์ hero-walk-sw-review.png และ hero-walk-nw-review.png ใน art-production/v32/ เป็นภาพสำหรับตรวจเท่านั้น สถานะ needs-review ไม่ใช่ภาพที่อนุมัติแล้ว

## ที่มาของภาพ
สร้าง/แก้ด้วย imagegen โดยใช้ภาพเดิมเป็น reference และ transparent_background=true คำสั่งของรอบที่บันทึกไว้ 37 รายการอยู่ใน art-production/v32/prompts.json มีทั้งรอบที่เลือกและไม่เลือก ไม่ได้อ้างว่าทุกคำสั่งผ่านคุณภาพ รายการที่ติดตั้งจริงและต้นฉบับก่อนหน้าอยู่ใน integrated.json / integrated-atlases.json

คำสั่งรอบแก้ท้ายบางภาพและภาพ loot ไม่ได้อยู่ในชุดบันทึก prompt นี้ จึงไม่อ้างว่าชุด prompt ครบถ้วน ภาพผลลัพธ์ที่เลือกอยู่ในแพตช์แล้ว การตรวจและการเลือกยังต้องยึดภาพจริงและ metadata ของคลิป
