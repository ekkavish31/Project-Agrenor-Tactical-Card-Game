# ตรวจบนเครื่องที่เล่นจริง

เปิดเสียง/เอฟเฟกต์ในสนาม เลือกภาพแบบประหยัดเครื่องเพื่อลดDPRเป็น1 ลดอนุภาค และจำกัดการวาดราว30FPS เพลงกับเสียงยังปรับแยกได้

กดF8หรือปุ่มวัดความลื่น แสดงช่วงเวลาระหว่างเฟรมที่เกมวาดจริง กดบันทึกผลเครื่องนี้เพื่อได้JSON ไม่มีการส่งข้อมูลออกเอง ช่วงhitstop/สโลว์โมชันหรือแท็บซ่อนมีผลต่อค่าที่วัด จึงไม่ใช้ตัวเลขนี้เป็นการรับรองเครื่องอื่น

ลองทั้งฉากป่า/ฝน/บอส3×3 หมุนกล้องและใช้เวทร่าย แล้วทดสอบจบสู้/กลับหมู่บ้าน ฟังเสียงหูฟังและลำโพงจริงเพื่อปรับระดับเพลง/เอฟเฟกต์ตามต้องการ การทดสอบอัตโนมัติไม่ได้แทนการฟังบนอุปกรณ์นั้น

ครอปหน้า: เปิดct-portrait-review.html เลือกตัวละคร ปรับX/Y/ขนาดและบันทึก (ต้นฉบับภาพการ์ดไม่เปลี่ยน) เมื่อเปิดผ่านเว็บไซต์เดียวกัน เกมอ่านค่าที่บันทึกหลังโหลดใหม่; พฤติกรรมlocalStorageเมื่อเปิดfile://ขึ้นกับเบราว์เซอร์ ให้ส่งออกJSONแล้วกลับมาเกม → เสียง/เอฟเฟกต์ → นำเข้าครอปหน้าCT เพื่อใช้ค่าแน่นอน แม้เปิดแบบfile://
