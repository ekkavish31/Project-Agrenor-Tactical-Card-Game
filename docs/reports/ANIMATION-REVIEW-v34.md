# ผลตรวจภาพ v34 — 18 ต.ค. 2026

## ติดตั้งแล้ว
- ปุ่ม UI เจน 8 ปุ่มใน atlas โปร่งใส 4×2: ถอย/หมุนซ้าย/หมุนขวา/ตั้งค่า และซูมเข้า/ซูมออก/พอดีจอ/เต็มจอ ใช้ CSS แสดงแต่ละช่องจาก PNG ต้นฉบับ
- ภาพหน้าสรุปกลับหมู่บ้าน 1536×1024; แสดงในหน้าผลการต่อสู้เดิมแล้ว การเดินทางกลับเคลื่อนไหวยังค้างใน TODO
- Coral Golem, Frost Queen, Void King, Yeti: special มุม SE/NE อย่างละ 3 เฟรม รวม 8 คลิปใหม่ เรียงเตรียม/ชาร์จ/ปล่อยผล (200/280/300ms, impact 480ms) SW/NW ใช้กลับภาพตามระบบเดิม
- ตรวจมือของ Queen/ดาบ Void King ไม่ย้ายมือกลางชุด ภาพแต่ละท่าไม่ปะปนกัน ครอปและจุดยืนแยกต่อเฟรม; ใช้อัตราส่วนสเกลเดียวต่อมุม ไม่ยืดท่าที่ยกอาวุธให้สูงเท่าท่าย่อ
- Cultist SW native 8 คลิปจาก 6 source cells ที่ตรวจผ่าน หนังสือไม่กลับมือ; windup=guard และ hit=idle+recoil ยังเป็น fallback
- PNG ที่เลือกทั้ง 7 ไฟล์เก็บ byte เดิมจากตัวสร้างภาพ ไม่แต่ง/ลบ/ตัดพิกเซลในไฟล์ ภาพที่ถูกปฏิเสธไม่รวมแพตช์

## ไม่อ้างว่าทำครบ
Hero SW/NW walk ยังซ้ำขา ไม่ติดตั้ง; Cultist NW/ตัวไม่สมมาตรอื่นยังไม่ผ่านการวาดทิศตรง; ท่าดีใจหลายเฟรมและสกิลบอสชนิด summon/heal/guard ยังไม่ครบ งานระบบล่าสุดและ Editor อยู่ใน TODO.md
Treant, Crystal King และ Bog Hydra มีท่าพิเศษ SE/NE เดิมอยู่แล้ว จึงรักษาของเดิม ไม่แทนด้วยภาพทดลอง
