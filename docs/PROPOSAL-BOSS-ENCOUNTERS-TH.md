# ข้อเสนอ: บทสนทนาและอีเวนต์ตอนเจอบอส (v98.1021)

> **สถานะ: ข้อเสนอ — ยังไม่ใช่ Canon** · เขียนตามคำสั่งเจ้าของเกม (23 พ.ย. 2026: "เพิ่มเนื้อเรื่องการเข้าเจอบอสแต่ละตัวผ่านบทสนทนาและอีเวนต์ · portrait บอสกำลังเจน") ด้วยข้อตกลงที่เจ้าของรับ ("ตามที่เสนอ")
> หลักที่ใช้: ไม่แตะ `CURRENT-ERA-CANON.md` · ไม่แต่งที่มา/ชื่อ/คำพูดของบอสที่ lore ไม่รองรับ (Canon `MAIN-STORY-CANON.md` §F: "ชื่อดันเจี้ยน/บอส" ยังเปิด) · บอสไม่พูดเป็นคำ มีแต่เสียง/การกระทำใน `[ ]` · ตัวเอกกับ `sib` พูดได้เฉพาะสิ่งที่เห็นหน้างานและข่าวลือใน `js/world-gen.js`

## ตรวจสถานะก่อนเขียน (แก้คำตอบรอบก่อน)
ผมเคยบอกว่าฉากตายตัวมีแค่บทตอนตัดปม — **ไม่ถูกต้อง** ตรวจจริงแล้ว `hungerPit`, `convoyPass`, `dragonLair` มี `intro` · `cut` · `half` · `win` · `lose` ครบอยู่แล้ว (`js/set-pieces.js`) ส่วนที่ขาดจริงคือ (1) อีเวนต์กลางสู้ (2) บทของบอสที่ขึ้นจากแผนที่โลก (3) ช่องใส่ portrait บอส

## Portrait บอส (กำลังเจน)
ชื่อไฟล์ที่ระบบหา: `assets/portraits/boss-<kind>-<neutral|angry|worry|happy>.webp` (`kind` = `wolf` `golem` `slime` `frostQueen` `bandit` `kobold` `hunger` `byrexael` `pumpkinBoss`) · ไม่มีไฟล์ = ใช้ไอคอน (🐺 🗿 🟢 ❄ 🗡 ⛏ 🩸 🐉 🎃) · วางไฟล์แล้วใช้ได้ทันที ไม่ต้องแก้โค้ด (ต้องเพิ่ม `kind` ใหม่ใน `BOSS_ID` ถ้าเป็นบอสตัวอื่น)

## ยังค้าง / ต้องให้เจ้าของตัดสิน
1. บอส 6 ตัวของโหมดยุทธวิธีเก่า (`treant` `crystalKing` `bogHydra` `coralGolem` `frostQueen`(ซ้ำกับโลก) `voidKing` ใน `js/tactics-core.js`) — ไม่มี lore เลย ยังไม่เขียนเรื่อง ถ้าอยากได้ ต้องให้ตั้งที่มา/ชื่อก่อน (Canon §F)
2. ก้อนหิว/Mip ติดเชื้อ (A10–A11)/Corvin ในฐานะบอส — ฉากปะทะ Mip และ Corvin ยังไม่มีในเกม (S2–S3) รอคำสั่งรายเฟสตาม `MAIN-STORY-IMPACT-REVIEW-TH.md`
3. บอสฟักทอง · ค่ายโจร · ถ้ำค้างคาว — มีบท `start/half/win/lose` อยู่แล้วใน `BattleTalk.scripts` ไม่ได้แก้ในรอบนี้ ยังไม่มีผู้พูดแบบบอสในบทพวกนี้
4. สำนวนบทพูดทั้งหมดเป็นร่างของผม ให้เจ้าของอ่านปรับ · เสียงของบอส (`[ ]`) เจ้าของอาจอยากให้บอสบางตัวพูดเป็นคำ — ต้องกำหนดที่มา/นิสัยก่อน
