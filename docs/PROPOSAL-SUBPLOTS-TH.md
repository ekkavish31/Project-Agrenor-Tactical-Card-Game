# เรื่องย่อยที่เพิ่มเข้าเส้นเดิม (v98.488) — พร้อมการตรวจความสมเหตุสมผล

> สถานะ: **ทำในเกมแล้ว** ตามที่เจ้าของสั่ง (14 พ.ย. 2026: "เพิ่มเนื้อเรื่องย่อย รายละเอียด ตัวละคร สถานที่ เข้าไปในเส้นเรื่องที่มีอยู่ ... อย่าให้ขัด อย่าให้ไม่สมเหตุผล") · ไม่เพิ่มข้อเท็จจริงใหม่ของโลก — ทุกเรื่องย่อยผูกกับข้อความที่มีอยู่แล้วใน Canon/Draft และผลต้องอ่านจาก "ธงที่ผู้เล่นสร้างเอง" เท่านั้น (ไม่มีเรื่องโผล่มาลอย ๆ)
> ชื่อตัวละคร/สถานที่ใหม่ทั้งหมดเป็นของที่ผู้ช่วยตั้งตามที่เจ้าของมอบหมาย (Canon §H) แก้ได้

## สิ่งที่ตั้งใจไม่ทำ (กันขัด)
- ไม่เล่าช่วงชีวิต/เหตุที่เซอร์เรียนถูกกัก (Canon §H ยังเปิด)
- ไม่ให้ผู้เฝ้าแสง/นักล่าเงาเผยหน้าตาจริงหรือชื่อเมืองก่อนหมุดที่กำหนด (Canon C7)
- ไม่ผูกเส้นที่เจ้าของแยกไว้ (วัตถุหิน · G. · หมาป่าเงา/พ่อของเรน · สายเลือดตัวเอก)
- ไม่ให้ความรู้เรื่องวิธีชำระ Mip มาจาก NPC ที่ยังไม่ตรวจ dependency — มาจากร่องรอยสำนัก + เมียร์ริส (มีใน Canon C5/C2)
