## ค. เส้นเรื่องใหม่ (เสนอเป็นเส้นรองเพิ่ม R8–R9)
- **R8 เส้นสหาย (loyalty arcs):** แต่ละสหายมีทางแยกเดียวช่วงสงคราม — ซิกริด (ภักดีแดนเหนือ vs ผู้เล่น) · บรัม (อดีตยามเมืองหลวง · "ค่าหัวผู้หนีทัพที่น่าเห็นใจ" ตรงกับระบบเล็กใน Draft §6.5) · เคียร์ (เพื่อนวัยเด็ก · ถูกชวนเป็นอัศวินเฝ้าเหมือง) · ลูน่า (ศึกษาซากโบราณ · ต่อ C-4) · ไม่มีใครตาย/ทิ้งทีมถาวร
- **R9 ร้านของเราในสงคราม (ต่อ F1):** ร้านผู้เล่นรับออร์เดอร์กองทัพ / ผู้อพยพ / ตลาดมืด → ราคาป้อนกลับ W2 และชื่อเสียงฝ่าย
- (ไม่เสนอเส้นที่เจ้าของแยกไว้: วัตถุหิน · G. · หมาป่าเงา/พ่อของเรน · สายเลือดตัวเอก)

## ง. กติกาออกแบบทางแยก (ให้ทั้งเกมอ่านง่าย)
1. **ทุกทางเลือกมี "ราคา" ไม่ใช่ถูก/ผิด** — แสดงเป็นชื่อเสียงฝ่าย/ทรัพยากร/ข่าว ไม่ใช่ศีลธรรม
2. **สะสมแทนปุ่มสุดท้าย:** ทางแยกเล็กเพิ่มคะแนนฝ่ายใน Chronicle แล้วไปตัดสินจริงที่ ⑂ ตอนจบ (e0) → ผู้เล่นรู้สึกว่า "ทางที่เดินมา" มีผล
3. **หน้าต่างโอกาสผูกหมุด:** ไม่ทำก่อนหมุดถัดไป → fallback เกิดเอง + ข่าวเล่าว่าเกิดอะไร
4. **คาบเกี่ยว = 1 อีเวนต์ เขียน Chronicle ได้หลายบรรทัด** ผ่าน `Titles.log` ที่มีแล้ว ไม่สร้างระบบเซฟใหม่
5. ใน**แผนผังเส้นเรื่อง** เสนอเพิ่มชนิดกล่อง "คาบเกี่ยว" (กรอบสองสี พาดข้ามหลายแถวในมุมมองเดินคู่ขนาน) และสถานะ "ข้อเสนอ" ให้แยกจากของที่อนุมัติแล้ว — ทำเมื่อเจ้าของเลือกรายการ
