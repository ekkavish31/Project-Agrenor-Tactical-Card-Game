# UI brush up · ระบบเยอะได้ แต่ปุ่มต้องน้อย

เป้าหมาย: เกมมีระบบได้มาก แต่ในแต่ละช่วง ผู้เล่นมีสิ่งที่ต้องกดแค่ไม่กี่อย่าง และการเล่นต้องไม่รู้สึกเหมือนนั่งทำงาน

## กติกา

### งบปุ่ม
- ปุ่มหลักไม่เกิน **4 ปุ่มต่อหน้าจอ** บวก "ออก/กลับ" 1 ปุ่ม (รวม 5)
- วัดด้วย `node tools/count-ui-buttons.cjs` ก่อนและหลังแก้หน้าใดก็ตาม
- เพิ่มระบบใหม่แล้วหน้าไหนเกินงบ ต้องรวมกลุ่มหรือย้ายเข้าไปในโลกก่อน merge

### ด่านตรวจ 3 ข้อ (ใช้ทุกครั้งก่อนตัดหรือย้ายปุ่ม)
1. **ยังทำได้ไหม**: ทุกอย่างที่ปุ่มเคยทำ ต้องมีทางทำในเกมครบ (เดินไปหา · คลิกของในฉาก · รายการของที่อยู่ใกล้) ถ้ายังไม่มีทางแทน ห้ามตัด
2. **มีการตัดสินใจไหม**: การกระทำที่ทำซ้ำบ่อยต้องมีอะไรให้เลือก เสี่ยง หรือลุ้น ถ้าไม่มี ให้ทำให้สั้นลงหรืออัตโนมัติ ไม่ใช่ทำให้ยาวขึ้น
3. **ครั้งที่ 50 ยังสนุกไหม**: ครั้งแรกเดินไปหาคนขายได้ แต่ครั้งต่อไปต้องมีทางลัด (เช่น เปิดร้านจากหน้าเมืองเมื่อเคยไปแล้ว)

### หลักเสริม
- ระยะทางต้องมีความหมาย: ระหว่างทางมีโอกาสเจอคน ของ หรือเหตุการณ์
- ทำซ้ำได้ แต่ผลไม่ซ้ำ (เช่น ปลาหายาก 5%)
- ไม่ลงโทษคนที่ไม่ทำ: ไม่รดน้ำ 1 วัน ผักโตช้าลง ไม่ตาย
- ทำให้อัตโนมัติเป็นรางวัล: บัวรดน้ำใหญ่ · สปริงเกอร์ · จ้างคนงาน · "เก็บเกี่ยวทั้งหมด" ปลดล็อกทีหลัง
- ผู้เล่นเลือกสไตล์เอง: ทำไร่เองได้ หรือจ้างคนดูแลแล้วออกผจญภัย
- ของที่ยังล็อกรวมไว้ที่เดียวเป็นบรรทัดจาง ๆ พร้อมเงื่อนไข แทนปุ่มเทากระจายทั่วจอ
- ปุ่มกลุ่มมีจุด "ใหม่!" เมื่อมีของเพิ่ม
- ของในฉากที่คลิกได้ต้องเรืองหรือมีขอบเมื่อชี้ และมีรายการ "สิ่งที่อยู่ใกล้" สำหรับจอยและจอสัมผัส
- ตำแหน่งคงที่: Esc = ย้อนกลับเสมอ · ปุ่มปิดมุมเดิม · ปุ่ม 1–4 ตรงกับปุ่มหลัก
