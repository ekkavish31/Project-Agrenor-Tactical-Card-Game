# คู่มือแอนิเมชันตัวละคร v03

ไฟล์ `animation-data.js` และ `animation-data.json` เป็นรายการเฟรมชุดเดียวกัน ภาพ PNG พื้นหลังโปร่งใสอยู่ใน `assets/characters/hero/` แยกภาพจริงตามท่าทาง ไม่ใช่ขยับภาพยืนแทนทุกกิจกรรม

## ชื่อไฟล์

`hero_{ชุดหรืออาวุธ}_{กิจกรรม}_{ทิศ}_{ลำดับสองหลัก}_{ช่วงท่า}.png`

ตัวอย่าง `hero_sword_attack_right_03_impact.png` คือ ฮีโร่ ชุดดาบ โจมตี หันขวา เฟรม 03 จังหวะกระทบ

- `daily` ชุดช่างและชีวิตประจำวัน; `sword`, `hammer`, `unarmed` ชุดผจญภัยตามอาวุธ
- `idle` ยืนหายใจ; `stretch` ยืดเส้น; `yawn` นั่งหาว; `walk` เดิน; `run` วิ่ง 6 เฟรม
- `smelt` หลอม; `forge` ตี; `quench` ชุบ; `meal` กินอาหาร; `rest` พักหายใจ; `sleep` หลับ
- `attack` โจมตี; `hit` รับการโจมตี; `cast` ร่ายพลัง
- `front` หน้าตรง; `right` หันขวา; การเดินไปซ้ายกลับภาพด้วย transform ที่ runtime
- `ready` เตรียม; `windup` ง้าง; `impact/contact` กระทบ; `followthrough` ตามแรง; `recover` คืนท่า; `hold` ค้างท่า

## ข้อมูลหนึ่งชุดท่า

```js
HERO_ANIMATIONS.clips['sword.attack'] = {
  loop: false,
  anchor: [0.5, 1],
  canvas: [384, 384],
  frames: [
    {src: 'assets/characters/hero/hero_sword_attack_right_01_ready.png', ms: 180},
    // ...
    {src: 'assets/characters/hero/hero_sword_attack_right_03_impact.png', ms: 110, event: 'impact'}
  ]
};
```

`ms` คือเวลาแสดงเฟรมหน่วยมิลลิวินาที `event` เป็นชื่อสัญญาณให้ระบบเอฟเฟกต์ใช้ ไม่ควรหักทรัพยากรหรือให้รางวัลซ้ำทุกครั้งที่วาดเฟรม เหตุการณ์ของหนึ่งรอบต้องทำเพียงครั้งเดียว ความสำเร็จงานและค่าความเสียหายยังอยู่ในระบบเกม

## จุดยึดและขนาด

ทุกเฟรมเป็นผืนโปร่งใส 384 × 384 anchor normalized [0.5,1] (กลางขอบล่าง) และปลายเท้าอยู่ประมาณ y=378 แต่ละแผ่นต้นฉบับใช้สเกลเดียวกันทุกเฟรม ไม่ขยายภาพนั่งให้สูงเท่าภาพยืน เพื่อรักษาสัดส่วน ห้าม trim แล้วขยายตาม bounding box แยกทีละเฟรม เพราะทำให้ตัวใหญ่เล็กสลับกัน

ตำแหน่งปลายเท้าอาจต่างเล็กน้อยตามท่า ภาพ AI ยังอาจมีความคลาดเคลื่อนของอาวุธ/สัดส่วนระหว่างเฟรม ควรตรวจท่าจริงก่อนเพิ่มจำนวนเฟรมในอนาคต ไม่ควรใช้การยืดภาพเพื่อแก้สรีระ

## เพิ่มตัวละคร

1. สร้างโฟลเดอร์ใหม่ใน `assets/characters/{characterId}` โดยใช้ทิศ สเกล ผืนภาพ และจุดยึดชุดเดียวกัน
2. สร้างเฟรมตามความหมายเดิม และเพิ่ม manifest ด้วย key ท่าเดิม เช่น `sword.attack`
3. จัดระยะเวลาและ `impact` ให้ตรงการสัมผัสจริง ไม่ให้เอฟเฟกต์เกิดระหว่างง้าง
4. ท่าวนใช้ `loop:true` ส่วนท่าทำกิจกรรม/โจมตีจบแล้วกลับ idle
5. สลับ idle หายใจ–ยืดเส้น–นั่งหาวเฉพาะช่วงว่าง ห้ามท่าพักแทรกกิจกรรมที่ยังทำไม่จบ
6. ทดสอบทั้งพื้นสว่าง/เข้ม การกลับภาพซ้าย การยกเลิกท่า และโหมดปิดแอนิเมชัน

## หมายเหตุภาพต้นฉบับ

ภาพสร้างจาก imagegen ชุดเดียวกับตัวละครเดิมและตัดเป็นเฟรมด้วย ImageMagick โดยแยกชิ้นส่วนจาก alpha เพื่อเก็บอาวุธที่ยื่นข้ามช่องและตัดเศษภาพข้างเคียงออก อาวุธยาวบางเฟรมชิดขอบแผ่นต้นฉบับ ควรเผื่อพื้นที่อาวุธให้มากขึ้นในการสร้างรุ่นถัดไป การใช้ภาพพร้อมชื่อมาตรฐานนี้ไม่ใช่ rig 3D

ชุด sword.attack ใช้เฟรมเตรียมเดิมเป็นช่วงคืนท่าแทนเฟรมตามแรงที่ปลายดาบถูกตัดจากภาพต้นฉบับ เพื่อไม่แสดงอาวุธขาด การเพิ่มเฟรมตามแรงใหม่ต้องเผื่อขอบภาพให้ครบปลายดาบ
