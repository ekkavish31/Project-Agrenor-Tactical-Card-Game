# Project A — Roadmap (ร่าง 15 ต.ค. 2026)

เป้าหมาย: เกมที่เล่นจบได้ มีเนื้อเรื่อง มีความคืบหน้า ตัวละครพัฒนาได้ มีเหตุผลให้ grinding และเล่นซ้ำ และมีความท้าทาย

## หลักการ
- วางโครงเรื่องสั้น ๆ ก่อนเจนภาพจริงจัง (ชื่อ พื้นที่ บอส ไอเทม และ prompt ภาพขึ้นกับโลกของเกม)
- ทำเป็นเวอร์ชันละก้อน แต่ละก้อนเล่นได้จริง
- ภาพของที่นิ่งแล้วเจนได้เลย ส่วนที่ยังเปลี่ยนได้ใช้ภาพชั่วคราวไปก่อน
- ภาพต่อตัวละครให้น้อยที่สุด (ดู "มาตรฐานภาพตัวละคร")

## วงจรหลักของเกม
หมู่บ้าน (คราฟต์ ซื้อขาย รับเควส พัฒนาตัวละคร) → ผจญภัย (แผนที่สุ่ม ต่อสู้ เก็บของ) → กลับมาคราฟต์ของที่ดีขึ้น/ปลดการ์ด → ไปพื้นที่ที่ยากขึ้น หรือเล่นพื้นที่เดิมในระดับที่ยากขึ้น

- [ ] รายชื่อตัวละครหลัก: ตัวเอก + เพื่อนที่จะเข้าทีม (ใครเป็นผู้นำทีมได้บ้าง)

## M3 · ความคืบหน้าและการพัฒนาตัวละคร (v16–17) — หัวใจของการ grinding
- [ ] เลเวลตัวละคร → ค่าสถานะ + ทักษะ/การ์ดที่ปลดตามเลเวล (ต้นไม้ทักษะต่อตัว)
- [ ] อุปกรณ์มีขั้นและความหายาก · ของดีต้องใช้วัตถุดิบจากพื้นที่ยาก (ผูกการคราฟต์กับการผจญภัย)
- [ ] การ์ดเป็นรางวัล: ดรอป/คราฟต์/ซื้อ · สมุดสะสมการ์ด · อัปเกรดการ์ด
- [ ] เพื่อน: เลเวล · ความสนิท · เควสส่วนตัว · ปลดเป็นผู้นำทีมได้
- [ ] เลือกผู้นำทีม (ตัวเอกคนอื่นเล่นแทนได้)

## M4 · เนื้อเรื่อง (v18–19)
- [ ] ระบบบทสนทนา/ฉากเล่าเรื่อง (กล่องข้อความ + รูปหน้า + ตัวเลือก)
- [ ] เควสหลักแบ่งเป็นบท · ปลดพื้นที่ตามเรื่อง (ไม่เปิดหมดตั้งแต่แรก)

- [ ] หมู่บ้านเติบโตตามเรื่อง (ร้าน/สิ่งก่อสร้างใหม่ ของขายดีขึ้น)
