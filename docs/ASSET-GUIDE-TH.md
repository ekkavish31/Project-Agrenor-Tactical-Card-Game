# ชุดภาพตัวละครและอุปกรณ์สนามทดลอง v04

สร้างด้วย imagegen แบบ built-in จากภาพอ้างอิง `assets/adventurer-unarmed-idle.png` ของเกมเดิม ไม่ใช้ 3D rig

## โครงสร้าง
- `hero_{direction}_{pose}.png` ขนาด 384 × 384 RGBA
- ทิศ: SE, SW, NE, NW
- ท่า: idle, walk-left, walk-right, windup, strike, guard, hit, down
- จุดยืนกลางพื้นภาพ: [192,360] หรือ normalized [0.5,0.9375]
- `manifest.json` และ `../../tactics-sprites.js` มีข้อมูลชุดเดียวกัน
- `right` / `left` คือจุดจับหลัก/รอง normalized ของภาพ
- `rotation` มุมเริ่มต้นของอาวุธในองศา โดยภาพอาวุธตั้งชี้ขึ้นที่ 0°
- `rightBehind` / `leftBehind` บอกลำดับภาพอุปกรณ์กับตัวละคร
- equipment แต่ละชิ้นมี `pivot` คือจุดจับ normalized ในภาพอุปกรณ์ ใช้เลื่อนจุดนี้ให้ตรงกับมือ

## ข้อจำกัดของชุดต้นแบบ
SE และ NE วาดขึ้นใหม่แยกจริง ส่วน SW/NW เป็นภาพสะท้อนพร้อมจุดจับสะท้อน จึงสลับความถนัดของมือทางกายวิภาคได้ หากต้องรักษามือขวา/ซ้ายอย่างเคร่งครัด ต้องแทนสองทิศนี้ด้วยภาพที่วาดใหม่

ท่าละหนึ่ง key pose ในการโจมตี ท่าเดินสอง key poses; runtime จัดลำดับและเวลาเอง ยังไม่ใช่เฟรมคั่นเต็มรูปแบบทุกท่า การสร้างท่าร่ายเวทหรือทุบสองมือเฉพาะเพิ่มเติมภายหลังควรคงขนาดร่างกายและ ground anchor นี้

จุดมือของมือที่ถูกผ้าคลุมบังเป็นค่าประมาณ ระหว่างแก้เฟรมใหม่ให้ตรวจภาพซ้อนกับอาวุธจริงเสมอ อาวุธชุดนี้เป็นภาพมุมเดียวเพื่อพิสูจน์ระบบประกอบก่อน; การหันปลายอาวุธเข้าหากล้องต้องเพิ่มภาพมุมอื่น ไม่ใช่หมุน 2D อย่างเดียว

## ชุด prompt ที่ใช้
1. ตัวละคร: ตัวละครต้นฉบับผมสีน้ำตาล ผ้าคลุมเขียว เสื้อครีม เกราะหนัง รองเท้าหนัง; sprite sheet 4×4, กล้อง isometric 30°, แถวบนสองแถว SE แถวล่างสองแถว NE; ท่ายืน เดินซ้าย เดินขวา ยกมือเตรียมโจมตี ฟันมือเปล่า ตั้งรับ โดนโจมตี ล้ม; มือกำเปล่า ไม่มีอาวุธ โล่ หรือเอฟเฟกต์ติดตัว; พื้นโปร่งใส
2. อุปกรณ์และวัตถุ: sprite sheet 4×2; แถวแรกดาบเหล็ก ค้อน โล่ไม้ ไม้เท้าผลึกฟ้า; แถวสองต้นโอ๊ก หิน ตอไม้ รั้วไม้; ภาพวาดแฟนตาซี isometric 30°, แยกวัตถุเต็มชิ้น ไม่มีมือหรือพื้น; พื้นโปร่งใส

หลังเจนใช้ alpha-connected components แยกวัตถุ ปรับเข้า canvas และวัดจุดจับด้วยสายตา ภาพเดิมไม่มีการลบอาวุธด้วยโค้ด เพราะชุดร่างกายใหม่ไม่มีอาวุธตั้งแต่ต้น
