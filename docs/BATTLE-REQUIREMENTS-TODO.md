- [ ] ยังต้องทดสอบในเบราว์เซอร์จริงและตรวจภาพ/การโหลด Asset ทุกชนิด

- [ ] เปลี่ยน Battle Ground Editor เป็น Visual Map Editor: พรีวิวแผนที่ด้วย renderer และ Asset จริงชุดเดียวกับตอนเล่น; ตัวเลือก texture/object เป็น thumbnail ภาพจริง คลิกเลือก/วาง/แก้ไขบนแผนที่ได้ทันที; คงข้อมูลเชิงเทคนิคไว้เบื้องหลังแทนการใช้ block code เป็น UI หลัก
- [ ] เพิ่มคุณสมบัติ Collision แยกจากภาพ Asset: เดินผ่านไม่ได้ (ค่าเริ่มต้นของ preset นี้), เดินผ่านได้, เดินผ่านได้แต่จมบางส่วน และ Custom Collision ที่กำหนดรูปทรง/พื้นที่ได้
- [ ] เพิ่ม Occlusion Mask ต่อ Object เพื่อกำหนดพื้นที่ที่บังตัวละคร โดยค่าเริ่มต้นของ preset นี้ใช้ Occlusion Mask; รองรับแก้ไข/ดู Mask ใน Editor
- [ ] ค่าเริ่มต้นเมื่อบังตัวละคร: ความทึบ 55% (alpha/opacity ต้องระบุความหมายให้ชัดใน UI ว่า 55% ทึบ ไม่ใช่ 55% โปร่งใส); คืนค่าความทึบอย่างนุ่มนวลเมื่อพ้นพื้นที่บัง
- [ ] เพิ่มระดับจมตัวละคร 50% สำหรับวัตถุ/พื้นประเภทที่เปิดใช้การจม; แยกจาก Collision และ Occlusion เพื่อไม่ให้มีผลโดยไม่ตั้งใจ
- [ ] Transform ทุกอย่างให้สอดคล้องกัน: ขนาด, หมุน, flip X/Y และยืดตามแกนเฉียง 2.5D ต้องแปลง Collision/Mask/จุดยึด/ระดับจมตามไปด้วย โดยไม่อิงกรอบภาพที่ขยายอย่างเดียว
- [ ] กำหนดลำดับการวาดและจุดอ้างอิงให้สอดคล้องกับพื้น/footprint และตำแหน่งเท้าตัวละคร; รองรับ Object ใหญ่และภาพที่มีพื้นที่โปร่งใสรอบภาพ
- [ ] ทดสอบ Asset ปกติและ Asset ที่ขยาย/หมุน/กลับด้าน/ยืดแกน 2.5D รวมการเดินชน ขอบ Mask การบัง/คืนความทึบ ระดับจม การหมุนกล้อง และการบันทึก/โหลดแผนที่
- [ ] แผนดำเนินงานต้องเสนอและตรวจทานก่อนเริ่มเขียนโค้ด; งานนี้เป็นข้อกำหนดแผนงานเท่านั้น ยังไม่มีการแก้โค้ด
