## 1. สิ่งที่ตัดสินแล้ว (ห้ามเปลี่ยนโดยไม่ถามผู้ใช้)

**โลกและตัวละคร**
- โลกคือ Agrenor ยุคปัจจุบัน
- ตัวเอกเป็นเผ่าคล้ายมนุษย์ ไม่มีอาชีพตายตัว ผู้เล่นตั้งชื่อเอง
- เกมเริ่มต้นคนเดียว เพื่อน (บรัม ลูน่า เคียร์ ฯลฯ) เป็นชาวบ้านจนกว่าจะชวน
- ทีมออกเดินทางได้สูงสุด 4 คน ที่เหลือพักโรงแรม

**เวลาและทรัพยากร**
- นาฬิกามีตัวเดียว แบบผสม: เดินเองในหมู่บ้าน แผนที่ย่อย และห้องภายใน (`RATE` = 1 นาทีในเกมต่อ 1 วินาที ใน `js/world-state.js`) และการกระทำกับการเดินทางกินเวลาเพิ่ม
- เงิน ยา เสบียง และ HP มีชุดเดียว

**การผจญภัย**
- ใช้แผนที่โลกเท่านั้น ระบบแผนที่พื้นที่แบบเก่าลบแล้ว
  - กระเป๋าย้ายไป `js/bag.js`
  - เพื่อนของลานฝึกอยู่ใน `js/companions.js` ซึ่งใช้ `s.village.party`

**ธาตุ (`js/elements.js`)**
- มี 9 ธาตุ Kaelam: Elu แสง · Sylfae ลม · Dephor น้ำ · Caelim สายฟ้า · Fren ไฟ · Lutha พฤกษา · Yalm น้ำแข็ง · Nytha ราตรี · Grat ผืนดิน
- แพ้ชนะตามธรรมชาติของธาตุ ไม่ใช่วงต่อกัน ตารางอยู่ใน `STRONG` พร้อมเหตุผล
  - ตีธาตุที่ชนะทาง ×1.3 · ตีธาตุที่แพ้ทาง ×0.7
- ธาตุลับที่ 10 คือโกลาหล ×1.2 กับทุกธาตุ
- ธาตุลับที่ 11 คือผสาน ×1.1 กับทุกธาตุ และรับความเสียหาย ×0.9
- ธาตุลับแสดงเป็น ??? จนกว่าจะค้นพบ
- ในเกมต้องมีตารางธาตุให้ดู (ปุ่ม ◈ ธาตุ) และมี tip ได้เปรียบ/เสียเปรียบตอนเลือกการ์ด

**ความสูงในสนามรบ**
- ปีนขึ้นได้ 1 ระดับ กระโดดลงได้ 2 ระดับ (การ์ดปีนป่ายเพิ่มเป็นขึ้น 2 ลง 3 และไม่เสียแต้มเดินขึ้นเนิน)
- ตก 1 ระดับไม่เสีย HP ตก 2 ระดับขึ้นไปเสีย 5 ต่อระดับ
- ตีประชิดต่างระดับได้ไม่เกิน 1 (ตัวที่บินได้ไม่จำกัด)
- ยืนสูงกว่าเป้าตีแรงขึ้น ±10% ต่อระดับ สูงสุด ±30%
- พื้นที่ระดับเดียวกันต้องราบ ไม่มีทางลาดอัตโนมัติ
- พื้นสนามใช้ตัววาดตัวเดียวคือ `js/terrain-height-art.js`

**หมู่บ้านและ editor**
- หมู่บ้านประกอบจาก asset แยกชิ้น
- editor ต้องรู้สึกเป็นมืออาชีพ: เลือกทีละชิ้น ยืนยัน OK/ยกเลิก มีตัวเลือกแบบภาพ และทุก editor มีปุ่ม push

**อุปกรณ์**
- New Game / Continue เปิดเต็มจอเป็นค่าเริ่มต้น
- รองรับแท็บเล็ตและมือถือแนวนอน (`js/touch.js`) ส่วนมือถือแนวตั้งให้ขึ้นหน้าบอกให้หมุนเครื่อง

**ภาพ**
- พื้นสนามและวัตถุในสนามวาดด้วยโค้ด
- อาวุธและโล่ถือเฉพาะตอนโจมตีหรือป้องกัน นอกนั้นสะพายหลัง

## 2. สิ่งที่เป็นการเดา / ยังไม่ได้ตรวจบนเครื่องจริง (ระวังเวลาแก้)

- การจับคู่ชื่อ Kaelam กับธาตุเดิม และตารางแพ้ชนะทั้งหมด เป็นการออกแบบของ Claude รอ lore จริงจากผู้ใช้
- บ้านใหม่ 6 หลัง (`npc10`–`npc15` ใน `village-town.html` base list) วางตำแหน่งคร่าว ๆ ยังไม่มีถนน ขนาดเริ่มต้นตั้งไว้ที่ `js/village-asset-edit.js` (sx/sy 0.73)
- ระบบสัมผัสบนแท็บเล็ตและมือถือ กับการเปิดเต็มจอ ยังไม่เคยลองบนเครื่องจริง
- ความเร็วนาฬิกา `RATE` = 1 ยังไม่ได้ฟังความเห็นผู้ใช้
- ตัวเลขสมดุลทั้งหมดยังไม่ได้ลองเล่นจริง ได้แก่ ความสูง ธาตุ ของดรอป ราคาในเมือง และค่าจ้างเพื่อน (บรัม 60 / ลูน่าต้องคุย 3 วัน / เคียร์ชวนได้เลย)
- ห้องภายในในเกมจริงเปิดผ่าน `marketFrame` ยังไม่ได้ทดสอบครบทุกสถานที่ (กิลด์ วิหาร บ้านชาวบ้าน)
- ชาวบ้านที่ไม่มีภาพจากระบบลานฝึกเก่า (ซิกริด เรน ฯลฯ) เวลาอยู่ในลานฝึกจะใช้อาวุธสำรองตาม `FALLBACK` ใน `js/companions.js` และอาจไม่มี sprite

## 8. ข้อควรระวังสำหรับคนที่มาทำต่อ

- การแก้ `js/village-layout-v67.js` หรือ `js/game-settings.js` จะไม่ขึ้นในเบราว์เซอร์ที่ผู้ใช้เคยแก้ผังเอง จนกว่าเขาจะกด "!" ใน editor ถ้าเป็นไปได้ ให้ตั้งค่าเริ่มต้นในโค้ดแทน (ตัวอย่าง: ขนาดบ้านใหม่ใน `village-asset-edit.js`)
- ถ้าเปลี่ยน `world-gen` ให้สุ่มเพิ่มอีกจุดใน `tryGenerate` โลกที่ผู้เล่นเซฟไว้จะเปลี่ยนตาม ให้แยกเป็น random stream ของตัวเองแบบเดียวกับ `placeTowns`
- `WorldState.bind()` ผูก field แบบ non-enumerable เวลา `JSON.stringify` ของแผนที่โลกจะไม่บันทึก field เหล่านี้ (ตั้งใจให้เป็นแบบนั้น) ห้ามเขียนทับ `S.party = [...]` ด้วยอาร์เรย์ใหม่ เพราะ setter จะไปเขียนลงเซฟหลัก (ถ้าทำก็ได้ แต่ต้องรู้ว่ามันเกิดอะไรขึ้น)
- โค้ดหลายไฟล์เขียนแบบบรรทัดยาว เวลาแทรกคอมเมนต์ `//` กลางบรรทัด จะทำให้โค้ดหลังคอมเมนต์หายไปด้วย ให้ใช้ `/* */` แทน (เคยพลาดมาแล้วใน v94.00)
- หน้าใน iframe ต้องหา `GameHost` จาก parent ก่อนทุกครั้ง ห้ามอ่าน `localStorage` ของเซฟหลักตรง ๆ ตอนอยู่ในเกม เพราะ index จะเซฟทับ
