วัดด้วย `tools/audit-resolution.cjs` — เปิดหน้าเกมจริง ดักทุกครั้งที่วาดภาพ (canvas `drawImage` + `<img>`) แล้วเทียบ "ขนาดที่วาดจริงสูงสุด (พิกเซลจอ)" กับ "ขนาดไฟล์"
หน้าที่วัด: หมู่บ้าน (ซูมเข้านิดหน่อย) · ภายในสถานที่ · แผนที่ย่อย · แผนที่โลก · สนามรบ — จอ 1440×900 DPR 1 (จอ retina ต้องการภาพละเอียดขึ้น 2 เท่า)
**ข้อจำกัด:** ไม่เห็น CSS background-image · ไม่ได้เปิดหน้าการ์ดขยาย/คลังการ์ด/Asset Studio · ซูมหมู่บ้านแค่บางส่วน — ตัวเลข "ต้องการ" จึงเป็นขั้นต่ำ ไม่ใช่เพดาน

## ทำไมวาดย่อจากภาพใหญ่ถึงเสียเปล่า
- เบราว์เซอร์ย่อด้วย bilinear ตอน `drawImage` → ย่อเกิน ~2× เส้นจะแตก/ระยิบ ไม่คมเท่าย่อไฟล์ครั้งเดียวด้วยตัวกรองดี (Lanczos)
- แรม: ภาพ 1120×800 ถอดรหัสเป็น 3.4 MB ต่อใบ แม้วาดเป็นช่อง 75 px — การ์ด 70+ ใบ ≈ 240 MB
- ดาวน์โหลด/โหลดช้าบนเว็บ (GitHub Pages)

## ข้อเสนอ (ยังไม่ได้แก้ไฟล์ใด ๆ)
1. **การ์ด/ไอคอนธาตุ/กรอบ** — ลดเหลือ ~2× ของขนาดที่ใช้จริงสูงสุด (การ์ด 1120 → ~640, ไอคอนธาตุ 256 → 64, กรอบ 750 → 420) ปลอดภัยที่สุด: ภาพเดี่ยว ไม่มีพิกัดอ้างอิง
2. **ของตกแต่งภายใน/ไอคอน** — ลดเหลือ 2× ของขนาดที่วาด
3. **ชีตที่อ้างพิกัดเซลล์** (props, meadow-details, enemies/animations) — ห้ามย่อไฟล์ตรง ๆ ต้องแก้ตารางเซลล์ในโค้ดตามด้วย ต้องทำเป็นงานแยก
4. ต้องแก้ `size` ใน asset manifest ให้ตรงไฟล์ใหม่ (ไม่งั้น Asset Studio ย้ำว่าขนาดไม่ตรง) และกู้ต้นฉบับจาก git ได้ (commit ก่อนย่อ)
5. ตึกที่วาดใหญ่กว่าไฟล์ตอนซูมสุด: จำกัดซูม หรือขอภาพใหม่ — ตัดสินใจร่วมกับผู้ใช้
