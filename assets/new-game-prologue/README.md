# New Game Prologue — Illustration Drop Zone

The 13 planned 1920×1080 WebP images belong in `assets/new-game-prologue/images/`. No real images have been committed yet. See `data/new-game-prologue-assets.json` for the exact planned filenames and per-image art direction.

After adding an approved image, add its ID to `APPROVED_IMAGES` in `js/new-game-prologue-kit.js`. The New Game storybook then uses that image instead of the code-generated `SceneArt` backdrop.

This is NOT `assets/intro/` and must not affect the maker logo, video intro, or menu background.
