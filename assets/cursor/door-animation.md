# Door cursor · v98.1084
Built-in image generation. Original: door-source.webp (4×2); runtime: door-atlas.webp (8×1, 96 px cells; 48 px CSS). OS fallback: os-door.png / os-door@2x.png, fully open pose. Hotspot: (24, 6) CSS px. Opens, holds, closes at 100 ms per frame. Reduced motion uses the still open door.

Prompt: eight successive opening poses of a single arched wooden door, fixed camera/frame, ivory stone with restrained antique gold trim, warm interior glow, painterly fantasy JRPG UI, actual transparent background, no text/grid/scenery. Imported by cropping cells and normalizing alpha bounds to a common baseline; generated source preserved.
