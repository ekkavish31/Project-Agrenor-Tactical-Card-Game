# Ivory UI panel

`ivory-panel.webp`: hand-painted blank ivory parchment, leather edge, fine brass trim and leaf corners. Use a 12% nine-slice; keep the centre blank and place text in code. Generated with the built-in image tool and converted to WebP (quality 90) for runtime loading.

Prompt: single straight-on square parchment panel for Agrenor's seal-book UI; pale ivory paper, subtle grain, thin leather/brass edges and small engraved leaf corners; central 85% blank, stretchable straight border strips, no text, icons, ribbons, magic circle or perspective.

Consumers: `css/ivory-ui.css`, `js/npc-emote.js`. Used for HUD/quest frames, matching buttons, talk balloons and the Mip loading panel.
