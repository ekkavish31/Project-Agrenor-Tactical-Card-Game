ไฟล์จาก GitHub · งานที่แก้เก็บในเบราว์เซอร์นี้จนกด Push

Asset Studio v48

  1. เลือกหมวด → เลือกตัวทางซ้าย → ดูตารางท่า × ทิศ กดช่องเพื่อเปิดเครื่องมือตรวจเฟรม
  2. หน้านี้ใช้ไฟล์จาก GitHub โดยตรง ไม่ต้องเชื่อมโฟลเดอร์ในเครื่อง · กด ↻ รีเฟรช เพื่อโหลดรายการไฟล์ล่าสุด
  3. เปลี่ยนโฟลเดอร์เลือกเกมชุดใหม่ได้เสมอ สแกนใหม่โหลดข้อมูลและภาพจากโฟลเดอร์เดิมอีกครั้ง งานรอส่งออกต้องจัดการก่อนเปลี่ยน
  4. ตารางเล่นท่าพร้อมกันเพื่อเทียบจังหวะ ปรับความเร็วร่วมกันได้ ช่องกลับภาพแสดงป้ายชัดเจน ช่องว่างคือยังไม่มีข้อมูลท่านั้น
  5. กดช่อง → เล่น / หยุด / เลื่อนทีละเฟรม / ภาพซ้อน / เทียบเวอร์ชัน / จดปัญหา / ส่งชุดแก้ให้ AI และส่งออกชีทหรือ GIF
  6. ส่วนภาพและไฟล์ใต้ตารางใช้เปลี่ยนภาพ นำเข้าชีท กู้ภาพเดิม และคัดลอก prompt เครื่องมือชุดคำขออยู่ในเมนูเครื่องมือเพิ่มเติม
  7. กดใช้ภาพ = เก็บการแก้ไว้ในเบราว์เซอร์นี้ก่อน (เก็บประวัติเวอร์ชันให้) แล้วกด ⬆ Push ที่แก้ เพื่อส่งขึ้น GitHub เป็น commit เดียว · ต้องตั้ง GitHub token ก่อน
  8. ภาพที่ไม่มีเจ้าของอยู่ใน Objects → ไฟล์ยังไม่จัดหมวด ไม่ลบภาพต้นฉบับอัตโนมัติ
